# `CSV` reader의 escapechar 연결

`src/CSV.py`의 `CSV.__init__`에 keyword-only `escapechar: Optional[str] = None`을 추가하고 인스턴스 설정으로 저장했습니다. `open()`이 만드는 `csv.reader`에 이 값을 그대로 전달하므로 Python 표준 파서의 동작과 오류가 유지되고, 설정을 생략한 호출은 기존 기본값으로 동작합니다. 바이너리·텍스트 모드가 공통 reader 생성 경로를 사용하므로 별도 분기 없이 동일 설정이 적용됩니다.

`tests/test_csv.py`에는 표준 `csv.reader`와 파싱 결과를 비교하는 기능 테스트를 추가했습니다. 이슈의 escape된 인용부호와 escape된 구분자·backslash·인용 다중행을 확인하고, `rb`, `r`, `rt` 모드, 기본 `None` 및 doublequote 호환, Validator 처리 순서와 잘못된 설정의 오류 전파도 검증합니다.

이후 한국어·영어 사용 문서를 갱신하고 전체 테스트를 실행했습니다. 최종 결과는 [구현 종합 기록](../IMPLEMENTS.md)에 정리했습니다.
