# CSV reader 기능 테스트 실행

- 표준 `python -m unittest discover -s tests -p "test_csv.py" -v` 실행은 현재 환경에서 설치 패키지 `csvd2c`를 찾지 못해 시작되지 않았습니다.
- Python 3.14.5의 `python -S -`로 `src/__init__.py`를 `csvd2c` 패키지로 로드한 뒤 동일한 `test_csv.py` 테스트 검색을 수행했습니다. 전체 42개 테스트가 통과했습니다.
- 코드 변경과 테스트는 확인했으며, 한국어·영어 매뉴얼 반영과 전체 테스트 실행은 후속 단계입니다.
