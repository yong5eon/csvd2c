# Python 3.9·3.10 CI 실패 분석

- GitHub Actions 실행에서 실패 잡이 Python 3.9와 3.10인 것을 확인했습니다.
- 실패한 `escapechar=''` 검사는 Python 3.9·3.10의 표준 파서가 빈 값을 허용하므로 버전별 동작에 의존했습니다. Pylance에서 선택된 Python 3.12.10에서는 빈 문자열과 2문자 문자열 모두 `TypeError`를 발생시켰습니다.
- 테스트 입력을 `escapechar='xx'`로 변경해 지원 버전 전반에서 잘못된 설정을 검사하도록 했습니다. 전체 제품 동작은 변경하지 않았습니다.
- Pylance에서 선택된 Python 3.12.10으로 CSV 테스트 42개를 실행해 모두 통과했고, Python 3.14.5에서도 수정한 회귀 테스트가 통과했습니다.
- Python 3.9·3.10 CI 매트릭스는 아직 재실행하지 않았으므로 해당 버전의 최종 CI 결과는 확인되지 않았습니다.
