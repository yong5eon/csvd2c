# 여러 이슈 종료와 마지막 줄 검사

`buildPullRequest`는 `IR.md`의 마지막 비어 있지 않은 줄이 해당 이슈의 `Changes:` 경로인지 확인한다. `Closes`의 위치와 개수를 제한하지 않아 여러 이슈를 한 줄 또는 여러 줄에 작성할 수 있다.

릴리즈 노트 수집은 마지막 비어 있지 않은 줄만 해석하고 직전 줄의 중복 항목을 검사하지 않는다. 마지막 항목이 없으면 기존 브랜치 경로를 사용하며, 잘못된 마지막 항목은 오류로 처리한다.

공통 지침에 실제 해결한 이슈마다 플랫폼에 맞는 종료 구문을 기록하도록 명시했다. 판단은 [근거 기록](../context/1794063457322.md), 검증은 [작업 기록](../tasks/1794063457322.md)을 따른다.
