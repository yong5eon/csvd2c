# 열린 PR의 제목과 본문 갱신

- `createPullRequest`는 열린 PR이 있으면 푸시된 작업 문서와 템플릿으로 제목·본문을 다시 만들고 PR 수정 API로 전체를 갱신한다. 수동으로 작성한 제목과 본문은 교체된다.
- 새 PR과 같은 변경 로그 검사를 원격 쓰기 전에 수행한다. 기존 메타데이터·이슈 연결 동기화와 Draft 상태, 새 PR 생성 및 변경 사항 없는 브랜치 처리는 유지한다.
- [결정 근거](../context/1794059406404.md)와 [검증 기록](../tasks/1794059406404.md)을 참고한다.
