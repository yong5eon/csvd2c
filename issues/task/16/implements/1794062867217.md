# IR 문서와 공통 지침 연동

공통 Instructions와 csvd2c의 작업 지침에 `IR.md`의 제목과 변경 내용·유형·검증·확인 사항 형식을 직접 추가했다. GitHub PR과 GitLab MR에 적용하며 특정 플랫폼 템플릿 파일을 지정하지 않는다.

csvd2c의 PR 생성기는 `PR.md` 대신 `IR.md`에서 제목과 본문을 읽는다. 기존 `PR.md`는 대체 입력으로 사용하지 않으며, 이슈 문서와 `AGENTS.md`도 새 이름에 맞췄다. 기존 이슈 브랜치에는 `IR.md` 작성이 필요하다.

판단은 [근거 기록](../context/1794062867217.md), 실제 검증은 [작업 기록](../tasks/1794062867217.md)을 따른다.
