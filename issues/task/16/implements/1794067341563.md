# 에이전트 브랜치 PR 문서 연동

PR 생성 워크플로의 푸시 대상에 `copilot/**`, `codex/**`를 추가했다. 에이전트 브랜치는 기존 PR이 없으면 건너뛰고, 열린 PR의 변경 파일 목록을 페이지별로 조회해 삭제되지 않은 `issues/<유형>/<번호>/IR.md` 하나를 찾는다.

`createPullRequest`는 해당 경로의 `IR.md`와 변경 로그로 제목·본문을 생성해 기존 PR만 갱신한다. 후보가 없거나 여러 개이거나 파일 목록이 API 제한에 도달하면 오류로 중단한다. PR head가 이미 다른 커밋이면 오래된 실행을 건너뛴다. 이슈 브랜치의 기존 PR 생성 및 메타데이터 동기화는 유지한다.

에이전트가 이후 PR 본문을 변경하는 순서는 제어하지 않는다. 기존 에이전트 브랜치는 변경된 워크플로를 포함해야 하며 실제 원격 실행은 확인하지 않았다. 판단은 [근거 기록](../context/1794067341563.md), 검증은 [작업 기록](../tasks/1794067341563.md)을 따른다.
