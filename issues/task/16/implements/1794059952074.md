# PR 문서 표시와 footer 경로 처리

- `buildPullRequest`는 작업 문서를 `<details>` 대신 원문 링크가 있는 제목과 문서 내용으로 표시한다. 본문 길이 제한을 넘으면 기존처럼 문서 링크로 대체한다.
- 릴리즈 노트 수집은 마지막 비어 있지 않은 줄의 `Changes:`만 경로로 사용하고, 바로 앞의 비어 있지 않은 줄에 중복 항목이 있으면 실패한다. 마지막 줄에 항목이 없으면 기존 브랜치 경로를 사용한다.
- 네 칸 이상 들여쓰거나 탭으로 시작하는 줄은 기존과 같이 항목으로 취급하지 않는다. 명시된 경로와 파일 검증, 직접 push 및 릴리즈 노트 재사용은 유지한다.
- 본문 전체의 태그·코드 예제 해석을 제거했다. 마지막이 아닌 항목은 실제 경로로 인식하지 않으며 본문 끝의 예시는 footer와 구분하지 못한다.
