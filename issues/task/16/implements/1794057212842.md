# PR 본문 변경 로그 경로와 생성 조건

- `.github/scripts/create-pr-from-issue.mjs`의 `buildPullRequest`는 기존 이슈 종료 구문을 목록으로 유지하고 뒤에 이슈 디렉터리의 `CHANGELOG.md` 경로를 마지막 목록 항목으로 추가한다. 길이 제한으로 다시 렌더링할 때도 동일하다.
- `createPullRequest`는 새 PR 생성 전에 읽은 변경 로그가 없거나 공백뿐이면 경로가 포함된 오류를 발생시킨다. 이미 열린 PR 처리와 다른 문서·템플릿의 선택적 읽기는 유지한다.
- 구현 결정은 [근거 기록](../context/1794057212842.md), 테스트와 결과는 [작업 기록](../tasks/1794057212842.md)에 남긴다.
