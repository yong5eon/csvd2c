# PR 문서 제목 연동

`buildPullRequest`가 `PR.md` 첫 줄의 최상위 제목을 PR 제목으로 추출하고 나머지만 본문에 사용하도록 변경했다. 제목이 없거나 공백뿐이거나 256자를 넘으면 오류를 반환하고, 본문도 필수로 유지한다. README와 원본 이슈 제목으로 대체하지 않는다.

새 PR 생성과 기존 PR 갱신은 동일한 제목·본문을 사용한다. 기존 링크 변환, footer, Draft 및 이슈 메타데이터 동기화는 유지한다. 이슈 작업 지침과 현재 `PR.md`에도 제목 작성 규칙을 반영했다.
