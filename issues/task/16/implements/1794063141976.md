# IR 이슈 연결과 변경 로그 항목

공통 작업 지침의 `IR.md` 형식과 현재 이슈 문서에 `Closes`와 `Changes:` 항목을 추가했다. 실제 구문과 경로는 플랫폼 및 프로젝트 규칙을 따른다.

csvd2c의 `buildPullRequest`는 문서 마지막 두 항목이 현재 이슈와 변경 로그 경로에 일치하는지 확인하고 해당 본문을 중복 추가 없이 사용한다. 항목이 없거나 일치하지 않으면 PR 생성·갱신 전에 오류를 반환한다.

판단은 [근거 기록](../context/1794063141976.md), 실제 검증은 [작업 기록](../tasks/1794063141976.md)을 따른다.
