# CI의 PR 변경 로그 경로 수집

- `.github/workflows/ci.yml`은 병합 PR 본문의 `Changes:` 경로를 우선 사용하고, 해당 항목이 없으면 기존 `issues/<브랜치>/CHANGELOG.md` 경로를 사용한다.
- 이슈·비이슈 작업 기록 경로만 허용하며 잘못된 항목이나 중복은 실패한다. `<details>` 문서, 코드 펜스, 들여쓰기 코드와 HTML 주석은 본문의 실제 항목과 구분한다.
- 기존 Git 트리의 일반 파일·비어 있지 않음 검증, 직접 push와 기존 릴리즈 노트 재사용 분기는 유지한다. CI에서 실제 수집 코드를 모의 실행하는 테스트를 추가했다.
- 이후 사용자 요청에 따라 CI의 테스트 실행 단계는 제거했다. [후속 구현 기록](./1794058215604.md)을 참고한다.
- `AGENTS.md`와 `TASK.instructions.md`에는 비이슈 작업의 PR 작성·갱신 시 변경 로그 경로를 마지막에 기록하도록 안내했다.
- [결정 근거](../context/1794057719626.md)와 [검증 기록](../tasks/1794057719626.md)을 함께 참고한다.
