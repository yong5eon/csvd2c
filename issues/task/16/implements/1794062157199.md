# 이슈 PR 본문을 PR.md로 생성

- `AGENTS.md`에 사람과 에이전트의 이슈 작업 모두에 적용되는 `PR.md` 작성·갱신 기준을 추가했다.
- `buildPullRequest`가 이슈 디렉터리의 `PR.md`를 본문으로 사용하며 상대 링크를 해당 커밋의 GitHub 링크로 변환하고 이슈 종료·변경 로그 footer를 덧붙인다.
- `PR.md`의 누락·공백과 GitHub 본문 길이 제한 초과는 오류로 처리한다. 기존 변경 로그 검사와 제목·Draft 생성·기존 PR 갱신은 유지한다.
- [결정 근거](../context/1794062157199.md)와 [검증 기록](../tasks/1794062157199.md)을 참고한다.
