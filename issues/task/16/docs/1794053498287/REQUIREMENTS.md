# 요구사항

- 이슈 유무와 관계없이 요구사항 명세서, 계획서, 변경 로그와 작업 기록을 작성한다.
- 이슈가 없는 작업은 `tasks/<UNIX_TIMESTAMP>/`에 기록하고, 이슈 작업은 유형과 이슈 번호를 기준으로 기록한다.
- CLI·원격 에이전트가 즉시 확인받기 어려운 경우 중요한 미확정 사항은 보류하고 확정된 범위에서 작업한다.
- 원격 플랫폼의 브랜치와 PR 작업 흐름을 기록 경로의 기준과 구분한다.
- csvd2c에 맞지 않는 문서 지침을 실제 프로젝트 계약에 맞춘다.
- 지침의 기존 개발 원칙과 적용 가능한 문서·코드 정책을 유지한다.
- 관련 문서의 충돌, 기록 경로와 링크를 확인하고 실제 검증 결과를 기록한다.

## 제외 범위

- CI 동작 변경, 커밋·푸시, PR 생성 및 외부 이슈 변경
- 제품 코드와 사용자 매뉴얼의 기능 변경

## 인수 기준

- 이슈 유무에 관계없이 필수 문서와 동일한 단계별 기록 규칙을 적용한다.
- 원격 브랜치명과 이슈 기록 경로를 구분하고, 확인이 어려운 중요한 사항을 임의로 구현하지 않는다.
- 이슈 PR의 변경 로그 경로 형식과 커밋 트레일러 기준을 명시한다.
- 수정한 문서의 상대 링크와 지침 간 적용 관계가 유효하다.
