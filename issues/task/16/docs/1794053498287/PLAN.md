# 작업 계획

1. 작업 범위와 기존 지침의 충돌을 확인하고 기록한다. **완료**
2. `INSTRUCTIONS.instructions.md`와 `TASK.instructions.md`에 공통 작업 기록, 실행 환경과 보류·인계 규칙을 반영한다. **완료**
3. csvd2c의 README·상세 매뉴얼 지침에서 다른 제품의 내용을 정리하고 관련 지침의 적용 관계를 맞춘다. **완료**
4. 변경된 지침의 상호 일치와 기록·링크를 확인하고 결과와 제한사항을 정리한다. **완료**

커밋 메시지 트레일러는 사용자 결정에 따라 `Co-authored-by` 기본 포함으로 정리했다.

## 검증 방법

- 지침의 필수 문서, 이슈·비이슈 기록 위치, 원격 브랜치, 보류와 PR 표기 규칙을 확인한다.
- 수정 문서와 작업 기록의 상대 링크·앵커 및 공백을 확인한다.
- csvd2c 문서 지침에 다른 제품의 브로커 관련 규칙이 남지 않았는지 확인한다.
