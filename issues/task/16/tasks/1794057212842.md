# PR 본문 변경의 테스트 준비

- 기존 자동 PR 테스트를 변경해 마지막 두 목록 항목과 변경 로그 누락·공백 시 생성 차단을 확인하도록 준비했다.
- 변경 로그 외 문서·템플릿이 없어도 생성되는 경우, 기존 PR 본문을 수정하지 않는 경우와 본문 길이 경계도 확인한다.
- [결정 근거](../context/1794057212842.md)에 따라 변경 전 테스트와 구현 후 검증을 수행한다.
- 변경 전 `node --test --test-name-pattern 'createPullRequest rejects a missing changelog' .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행했다. 기존 코드가 PR 생성 요청까지 진행해 기대한 누락 오류가 발생하지 않는 실패를 재현했다. 테스트의 GitHub 응답은 모의 처리했다.
- 기존 PR 테스트에서도 변경 로그가 없는 경우를 사용해 기존 본문과 처리 흐름이 유지되는지 확인한다.
- 구현 후 `node --test .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 61개가 모두 통과했다. GitHub API는 모의 응답을 사용했다.
- 상세 매뉴얼과 루트 README를 검토했다. 변경 대상은 저장소 내부의 PR 생성 자동화로 csvd2c의 공개 API·설치·사용법이 아니며 해당 문서에 관련 자동화 설명도 없어 갱신하지 않았다.
- 변경 로그 수집 CI와 실제 GitHub PR 생성·수정은 이번 범위에서 수행하지 않았다.
