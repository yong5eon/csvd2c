# IR 문서와 공통 지침 분석

- 두 저장소의 브랜치와 기존 지침, csvd2c의 현재 PR 템플릿 및 자동화 입력을 확인했다.
- [요구사항](../REQUIREMENTS.md), [계획](../PLAN.md), [판단 근거](../context/1794062867217.md)를 기록했다.
- 저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 64개가 통과했다. `PR.md`만 있을 때 `IR.md` 누락으로 실패하는 경우도 확인했다.
- 현재 이슈 `IR.md`의 제목·본문·footer를 로컬에서 확인하고 두 공통 지침의 형식 및 기존 템플릿과 본문 내용이 일치함을 확인했다.
- 처음 지침 비교는 줄바꿈과 인코딩 차이를 처리하지 않아 실패했고, Python 재시도는 시작 환경의 편집 가능 패키지 오류와 입력 인코딩 문제로 실패했다. UTF-8과 줄바꿈을 명시한 PowerShell 비교는 통과했다.
- 상세 매뉴얼과 루트 README는 제품 사용법을 다루므로 개발 작업 자동화 입력 변경에 따른 수정이 필요하지 않다.
- 실제 GitHub Actions와 GitLab 자동화 실행, 원격 PR·MR 변경은 수행하지 않았다.
