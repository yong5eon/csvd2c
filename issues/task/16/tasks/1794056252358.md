# 검수·문서 영향·계획 지침 보완

- `INSTRUCTIONS.instructions.md`에 읽기 전용 검수와 별도 실행 권한을 구분했다.
- `AGENTS.md`의 코드 작업에 상세 매뉴얼·루트 README 영향 검토와 관련 지침 연결을 추가했다.
- `TASK.instructions.md`에서 작업 계획에 실제 해당하는 대상과 역할을 기재하도록 명확히 했다.
- 변경 범위와 판단은 [근거 기록](../context/1794056252358.md)에 남겼다.
- `git diff --check`를 통과하고 세 지침의 변경 차이를 확인했다. `python -S` 표준 라이브러리 검사로 인수 기준 10개와 문서 11개의 상대 링크·앵커 49개를 확인했다.
- 상세 매뉴얼의 한·영 신규 작성과 사용자가 원복한 동시 갱신 문장, 필수 작업 문서와 동일 타임스탬프 규칙을 확인했다.
- 제품 코드 변경이 없어 제품 테스트는 실행하지 않았다. CI 연동과 GitHub 원격 세션 검증은 사용자의 결정에 따라 이번 범위에서 제외했다.
