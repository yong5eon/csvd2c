- 기존 PR 생성기의 두 줄 검사와 릴리즈 수집의 직전 줄 중복 검사를 확인했다.
- [요구사항](../REQUIREMENTS.md), [계획](../PLAN.md), [판단 근거](../context/1794063457322.md)를 기록했다.
- 저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 69개가 통과했다. 여러 `Closes`를 한 줄과 여러 줄로 작성하는 경우와 마지막 경로 오류를 확인했다.
- 저장소 루트에서 `python -S -m unittest discover -s .github/scripts/tests -p test_release_notes.py`를 실행해 7개가 통과했다. 직전 줄에도 `Changes:`가 있을 때 마지막 경로를 사용하는 경우를 확인했다.
