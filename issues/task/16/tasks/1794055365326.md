# 공통·프로젝트 지침 검토

- 커밋 메시지 지침을 제외한 공통 지침 6개와 프로젝트 지침 3개를 검토했다.
- 지침 탐색·작업 지침의 중복 설명과 상세 매뉴얼·README 지침의 중복 및 프로젝트에 맞지 않는 내용을 정리했다.
- 유지한 계약과 판단 근거는 [관련 기록](../context/1794055365326.md)에 정리했다.
- `git diff --check`를 통과했다. `python -S` 표준 라이브러리 검사로 주요 계약 10개와 문서 17개의 상대 링크·앵커 40개를 확인했다.
- 첫 검증에서는 지침에 없는 `해당 디렉터리`라는 표현을 검사해 실패했다. 실제 표현인 `두 디렉터리의 존재 여부와 지침 파일 목록`을 확인하도록 검사 조건을 정정한 뒤 통과했다.
- 제품 코드 변경이 없어 제품 테스트는 실행하지 않았다. 원격 브랜치의 CI 연동과 GitHub 에이전트 세션 검증은 미완료다.
