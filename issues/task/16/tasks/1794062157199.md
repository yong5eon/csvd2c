# 이슈 PR 본문 연동 계획

- 기존 PR 자동 생성기와 템플릿, 작업 지침, 이슈 기록과 관련 테스트를 확인했다.
- 사용자에게 이 프로젝트의 이슈 작업에만 적용하고 사람과 에이전트 모두 같은 방식을 사용함을 확인했다.
- [결정 근거](../context/1794062157199.md)와 계획에 입력·출력, 기존 브랜치의 호환성 영향 및 검증 범위를 기록했다.
- 변경 전 테스트에서 기존 생성기가 `PR.md` 외 작업 문서 전문까지 PR 본문에 포함함을 확인했다.
- 저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 58개가 통과했다.
- 현재 이슈의 `PR.md`가 본문 그대로 사용되고 footer가 마지막에 추가되는지 로컬에서 확인했다. `git diff --check`도 통과했다.
- 제품의 공개 API·설치·사용법은 변경하지 않아 상세 매뉴얼과 루트 README는 갱신하지 않았다. 실제 GitHub Actions 실행과 PR 수정은 수행하지 않았다.
