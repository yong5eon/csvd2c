# PR 문서 제목 연동 분석과 계획

- 사용자 요청과 기존 제목 선택 방식을 대조하고 [요구사항](../REQUIREMENTS.md)과 [계획](../PLAN.md)을 갱신했다.
- 제목과 본문의 분리 및 오류 처리 결정은 [근거 기록](../context/1794062380913.md)을 따른다.
- 저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 63개가 통과했다. 제목 경계·누락, 본문 누락 및 새 PR·기존 PR에서 원격 쓰기 전 오류를 확인했다.
- 현재 이슈의 `PR.md`에서 제목과 본문을 분리하고 footer를 덧붙이는 결과를 로컬에서 확인했다.
- 최초 테스트 실행은 상위 작업 디렉터리에서 실행해 대상 파일을 찾지 못했다. 저장소 루트에서 다시 실행해 통과했다.
- 실제 GitHub Actions와 원격 PR 생성·갱신은 실행하지 않았다.
