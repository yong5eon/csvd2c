# 단계별 기록 보존 원칙 분석

- 기존 지침과 이전 단계별 기록을 확인해 삭제·대체 금지만으로는 후속 링크 추가를 명확히 금지하지 못함을 확인했다.
- [결정 근거](../context/1794058502204.md)에 따라 두 저장소의 대상, 브랜치와 기록 방식을 확정하고 요구사항과 계획을 갱신했다.
- 두 작업 지침에 완료·중단된 단계별 기록 보존, 새 기록에서의 정정, 진행 중 기록과 종합 문서의 갱신 및 승인된 정리 예외를 명시했다.
- 두 지침의 세 문단이 동일한지 확인하고 양쪽 저장소에서 `git diff --check`를 실행했다. 첫 문단 비교 스크립트는 문자열 검색에 실패해 비교 방식을 바로잡아 다시 통과했다.
- 문서 지침만 변경해 제품 테스트는 실행하지 않았다. Instructions 저장소에는 사용자 결정에 따라 별도 작업 기록을 만들지 않았다.
