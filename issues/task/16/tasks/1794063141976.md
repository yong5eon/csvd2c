# IR 항목 누락 분석과 계획

- `IR.md`에 항목이 없는 반면 자동화가 PR에 덧붙이는 현재 동작을 확인했다.
- [요구사항](../REQUIREMENTS.md), [계획](../PLAN.md), [판단 근거](../context/1794063141976.md)를 기록했다.
- 저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 70개가 통과했다. 새 PR과 기존 PR에서 항목 누락과 잘못된 이슈·경로가 원격 쓰기 전에 실패하는지 확인했다.
- 첫 실행에서는 테스트 입력의 문자열 치환이 특수 문자를 해석해 한 테스트가 실패했다. 테스트 입력 작성 방식을 수정한 뒤 전체 관련 테스트가 통과했다.
- 현재 이슈 문서의 두 항목이 생성 본문에 한 번만 포함되는지 확인했다. 첫 확인은 줄바꿈 방식 차이로 실패했으며 줄바꿈을 정규화한 확인은 통과했다.
- 두 공통 지침의 IR 형식과 항목이 일치함을 확인했다. 실제 GitHub Actions와 원격 PR 변경은 실행하지 않았다.
