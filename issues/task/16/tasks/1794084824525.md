# 후속 수정 검증

세 프로젝트에서 확인한 변경을 코드와 관련 테스트에 반영했다. [판단 근거](../context/1794084824525.md)

저장소 루트에서 `node --test --test-reporter=spec .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 72개가 통과했다. 심볼릭 링크 두 사례는 Windows의 링크 생성 권한이 없어 건너뛰었다. `python -S -B -m unittest discover -s .github/scripts/tests -p test_release_notes.py -q`는 7개가 통과했다.

네 저장소의 PR 생성기·관련 테스트와 릴리즈 수집 단계가 일치함을 확인했다. 앞선 DefPixel 검증에서는 같은 코드와 테스트를 Linux Node 24로 실행해 링크 두 사례를 포함한 74개가 통과했다. csvd2c에서는 Linux 테스트를 별도로 반복하지 않았다.

상세 매뉴얼과 루트 README는 제품 사용법을 다루므로 개발 자동화 변경에 따른 수정이 필요하지 않다. 이번 수정의 실제 GitHub Actions 실행과 원격 변경은 수행하지 않았다.
