# Draft PR 생성 변경 준비

- 이슈 브랜치 워크플로, PR 생성 요청과 기존 열린 PR 처리 및 GitHub REST API의 `draft` 계약을 확인했다.
- [결정 근거](../context/1794058913177.md)에 따라 요구사항과 검증 계획을 작성했다.
- 변경 전 새 PR 생성 테스트에서 `draft`가 없어 `undefined`와 `true`가 일치하지 않는 실패를 확인했다.
- 변경 후 저장소 루트에서 `node --test --test-name-pattern='createPullRequest (creates a new PR after a merged PR|skips an existing open PR without creating another)' .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 2개가 통과했다.
- `git diff --check`가 통과했다. 제품 API·설치·사용법이 바뀌지 않아 상세 매뉴얼과 루트 README는 갱신하지 않았다. 실제 GitHub PR 생성과 Actions 실행은 수행하지 않았다.
