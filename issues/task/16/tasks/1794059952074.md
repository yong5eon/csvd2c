# PR footer 변경 분석

- PR 리뷰, 문서 생성과 CI 수집 코드 및 관련 테스트를 확인했다.
- [결정 근거](../context/1794059952074.md)에 사용자 선택과 호환성 한계를 기록하고 요구사항과 검증 계획을 갱신했다.
- 변경 전 테스트에서 문서의 인라인 `</details>`가 CI에 `Invalid PR details markup` 오류를 일으킴을 재현했다. 비마지막 `Changes:`도 기존에는 경로로 사용했으며 PR 본문에는 `<details>`가 포함됐다.
- 저장소 루트에서 `node --test --test-reporter=dot .github/scripts/tests/create-pr-from-issue.test.mjs`를 실행해 관련 테스트 64개가 통과했다.
- `PYTHONDONTWRITEBYTECODE=1` 환경에서 `python -S -m unittest discover -s .github/scripts/tests -p test_release_notes.py -v`를 실행해 실제 CI 수집 코드를 모의 실행하는 테스트 7개가 통과했다.
- PyYAML로 변경된 워크플로의 YAML 구문을 확인했고, Pylance에서 수정한 Python 테스트 파일의 구문 오류가 없음을 확인했다.
- 제품의 공개 API·설치·사용법은 변경하지 않아 상세 매뉴얼과 루트 README는 갱신하지 않았다. 실제 GitHub Actions 실행과 PR 수정은 수행하지 않았다.
