# Copilot CLI 모델 선택 조사

- 기존 리뷰 처리 스크립트와 워크플로의 CLI 호출·설치를 확인했다.
- 공식 모델 선택 문서, CLI README와 기본 모델 문서 수정 제안을 대조했다. 사용 가능한 모델 지정 방법과 기본값의 불확실성은 [근거 기록](../context/1794061311673.md)에 정리했다.
- `npm view`로 조회한 패키지 버전은 `1.0.107`이지만 워크플로는 버전을 고정하지 않는다. 실제 Actions에서 설치·선택된 버전과 모델은 확인하지 않았다.
- PR 자동화나 리뷰 설정은 변경하지 않았고 실제 AI 요청도 실행하지 않았다.
