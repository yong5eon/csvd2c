# AI 기반 PR 본문 작성의 기존 구성 조사

- PR 템플릿, 푸시 워크플로, PR 생성기와 리뷰 처리 워크플로 및 Copilot CLI 호출을 확인했다.
- 기존 리뷰 처리에는 명시적인 모델 옵션이 없고, GitHub의 코드 리뷰 수준과 CLI 모델은 별개임을 공식 문서와 대조했다. 자세한 판단은 [근거 기록](../context/1794060925255.md)을 따른다.
- 로컬에서 `copilot --help`를 확인하려 했으나 CLI 설치 안내가 출력되어 실행할 수 없었다.
- 사용할 모델을 확인한 뒤 요구사항·계획을 구체화하고 구현과 검증을 진행한다. 실제 GitHub Actions나 AI 요청은 실행하지 않았다.
