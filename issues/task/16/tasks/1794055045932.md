# 공통 지침 위치 분리

- 사용자 요청과 기존 지침 목록, `task/16` 브랜치 및 `.github/instructions` 연결 대상을 확인했다.
- [요구사항](../REQUIREMENTS.md)과 [계획](../PLAN.md)에 공통·프로젝트 지침 분리를 반영했다.
- 이동 범위와 기존 IDE 연결의 영향은 [판단 기록](../context/1794055045932.md)에 정리했다.
- 공통 지침 7개를 `.instructions.assistant/`로 옮기고 `AGENTS.md`와 지침 탐색 안내를 두 디렉터리에 맞게 갱신했다. Python 지침은 프로젝트의 언어 예외를 따르도록 정리했다.
- `git diff --check`와 `python -S`를 이용해 지침 파일 구성과 상대 링크·앵커 13개를 확인했다. 기존 `.github/instructions` junction이 프로젝트 지침 위치를 유지하는 것도 확인했다.
- IDE의 공통 지침 자동 로딩이나 실제 원격 에이전트의 동작은 검증하지 않았다.
