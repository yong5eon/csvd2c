# PR 요약의 Copilot CLI 사용 결정

## 상황과 근거

[기존 구성 조사](./1794060925255.md)에서 리뷰 처리의 CLI 기본 모델과 코드 리뷰 수행 수준이 별개임을 확인했다. 사용자는 PR 요약에도 기존 CLI 기본 모델 설정을 사용하기로 선택했다.

## 결정과 영향

기존 Copilot CLI 실행의 인증 분리, 도구 비활성화, 응답 크기 제한과 오류 처리를 공유한다. PR 본문은 기존 작업 문서를 입력으로 받되 AI 요약을 템플릿의 변경 내용과 검증 항목에 반영하며, 이슈 footer와 기존 PR 생성·갱신 계약을 유지한다. AI 호출·응답 오류는 PR 쓰기 전에 실패한다.

코드 리뷰의 Lite 설정은 CLI 모델 설정이 아니므로 변경하지 않는다. 실제 Actions 권한과 모델 가용성, 요약 품질은 로컬 모의 테스트만으로 확인할 수 없다.

## 보류

작업 문서는 코드나 민감한 내용을 포함할 수 있으며 기본 모델을 사용하는 자동 호출은 외부 처리 대상과 입력 내용을 보장할 수 없다. 문서 전체를 자동 전송하는 구현은 진행하지 않았다. 위 계획은 실제 구현 결과가 아니다.
