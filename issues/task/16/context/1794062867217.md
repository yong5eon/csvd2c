# 플랫폼 공통 변경 적용 요청 문서 결정

## 상황과 근거

사용자는 `PR.md`가 GitLab MR을 포괄하지 못한다고 지적하고 `IR.md`라는 이름과 공통 지침에 현재 템플릿 내용을 직접 명시하는 방식을 선택했다. 기존 자동화는 csvd2c에서 `PR.md`를 읽으며 공통 Instructions에는 해당 작성 지침이 없다.

## 결정과 영향

이슈 작업의 문서 이름을 `IR.md`로 통일하고 공통 지침에 제목, 변경 내용·유형·검증·확인 사항을 포함한다. 특정 플랫폼의 템플릿 파일에 의존하지 않으며 비이슈 작업에 문서를 추가하지 않는다. csvd2c 자동화는 새 이름만 읽는다.

공통 원본과 csvd2c의 지침 사본은 독립 파일이므로 해당 내용을 각각 갱신한다. Instructions 저장소는 [기존 사용자 결정](../context/1794058502204.md)에 따라 `master`에서 별도 작업 기록 없이 변경한다. 다른 프로젝트의 CI는 이번 작업에서 변경하지 않는다.

관련 Node 테스트 64개와 현재 이슈 문서의 제목·본문·footer, 두 지침의 형식과 기존 템플릿 내용 일치를 로컬에서 확인했다. 실제 GitHub Actions와 GitLab 자동화는 실행하지 않았다.
