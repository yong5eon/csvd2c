# CI 테스트 실행 단계 제거 결정

## 상황과 목표

기존 CI에 릴리즈 노트 수집 테스트 실행 단계를 추가한 뒤, 사용자가 테스트 파일은 변경 시 검증용으로 남기고 CI 단계는 제거하도록 요청했다.

## 근거와 결정

해당 단계는 PR과 `master` push에서 모의 테스트를 실행하며, 릴리즈 노트 수집 자체에는 필요하지 않다. 수집 코드와 테스트를 변경하지 않고 단계만 제거한다. 테스트는 더 이상 이 단계에서 자동 실행되지 않으므로 관련 변경 시 직접 실행해야 한다.

## 영향과 검증 계획

수집 동작을 유지하면서 YAML 구문과 남은 단계 구성을 확인한다. 제품 공개 API와 사용법은 바뀌지 않아 상세 매뉴얼과 루트 README를 갱신하지 않는다.

로컬에서 YAML 구문과 단계 제거, 수집 단계 및 테스트 파일 유지를 확인했다. 실제 GitHub Actions 실행은 확인하지 않았다.
