# 변경 로그 검사 적용

## 상황과 근거

[후속 계획](../PLAN.md)에 따라 세 프로젝트에서 검증한 구현을 적용한다. 기존 CI는 선행 공백을 제거한 줄로 마지막 항목을 검증하고, PR 생성기는 변경 로그를 읽을 때 심볼릭 링크를 따라간다.

## 결정과 영향

CI에서 마커는 기존처럼 감지하되 원래 줄의 선행 공백을 보존해 형식을 검사한다. PR 생성기는 변경 로그를 읽기 전에 `lstat`로 링크 자체가 일반 파일인지 확인한다. 네 칸 이상·탭 들여쓰기의 폴백과 한계는 유지한다. 검증 결과는 [작업 기록](../tasks/1794084824525.md)에 남겼다.
