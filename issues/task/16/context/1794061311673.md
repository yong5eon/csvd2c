# Copilot CLI 모델 선택과 기본값 판단

## 상황과 근거

사용자가 기존 리뷰 처리에서 사용하는 Copilot CLI의 모델 지정 가능 여부와 기본 모델 조사를 요청했다. 기존 리뷰 처리의 CLI 호출은 `--model`을 지정하지 않으며, 워크플로는 패키지 버전을 고정하지 않는다.

[공식 모델 선택 문서](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/choose-a-model)는 `--model` 지정과 `/config model`을 설명한다. [CLI 저장소 README](https://github.com/github/copilot-cli/blob/main/README.md)는 기본 모델을 Claude Sonnet 4.5로 설명하지만, [문서 수정 제안 PR](https://github.com/github/copilot-cli/pull/5036)은 Claude Sonnet 5로 변경할 것을 제안하며 미병합 상태다.

## 해석과 결과

문서상 모델 지정은 가능하다. README와 미병합 제안이 다르고 실제 Actions 실행에서 선택된 모델을 확인하지 않았으므로 이 저장소의 현재 기본 모델을 확정하지 않는다. 모델 가용성은 플랜과 정책에도 좌우된다.

이전에 [보류 기록](./1794061001865.md)에서 외부 모델 입력 문제만으로 구현할 수 없다고 단정한 설명은 부정확했다. 기존 리뷰 자동화도 Copilot CLI를 사용하며, 실제 전달 범위와 처리 방식은 별도로 확인해야 한다. 이번에는 모델 문서만 조사하고 자동화 구현이나 실제 AI 요청은 수행하지 않았다.
