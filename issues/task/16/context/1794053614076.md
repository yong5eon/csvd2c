# 공통 작업 절차와 문서 지침 정리

## 근거와 결정

- 이슈 작업의 요구사항·계획·기록·검증은 유지하고, 이슈 유무에 따라 원본 확인과 기록 위치만 구분한다. 비이슈 작업에도 같은 필수 문서와 단계별 기록을 적용한다.
- 원격 브랜치는 플랫폼에서 제공하므로 이슈 유형·번호와 브랜치명의 일치를 요구하지 않는다. 기록 경로는 이슈 유형과 번호로 확인한다.
- 즉시 확인이 어려워도 중요한 미확정 사항을 추측하지 않으며, 독립적인 확정 작업은 계속하고 보류 사유를 남긴다.
- csvd2c의 현재 README와 패키지 설정을 근거로 브로커 관련 문구를 CSV·TSV와 입력 파일에 관한 안내로 교체한다.
- 기존 Python 언어 지침은 한국어 주석을 요구했지만 프로젝트의 코드 지침은 영어를 명시적 예외로 정한다. Python 지침에서 해당 예외로 연결한다.

## 영향과 검증

기존 고객 기능을 변경하지 않는다. 변경된 지침의 세부 일치와 링크는 후속 검증이 필요하다.
