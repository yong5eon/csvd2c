# 공통·프로젝트 지침의 필요성 검토

## 상황과 근거

사용자가 커밋 메시지 지침 외의 지침도 에이전트 관점에서 검토해 불필요한 내용을 제거하도록 요청했다. 공통 지침과 csvd2c 전용 지침을 읽고 적용 범위, 다른 지침과의 중복, 실제 프로젝트와의 관계를 확인했다.

## 결정과 영향

- 지침 탐색 문서에서 실제 지침 파일과 진입 문서에 이미 안내된 README 예시와 도구별 진입 파일 구성 설명을 제거했다. 프로젝트 지침을 확인하고 자동 로딩을 가정하지 않는 규칙은 유지했다.
- 작업 지침의 YAGNI·KISS 약어 설명은 공통 개발 지침과 인접한 요구사항 작성 규칙에 중복되어 삭제했다. 범위 확대 방지와 문제를 직접 해결하는 원칙은 유지했다.
- 상세 매뉴얼 지침의 한·영 동시 갱신 중복 문장과 README 지침의 입력 파일 전제 조건 중복 문장을 제거했다. 실제 패키지에 없는 extra 이름에 관한 언급도 정리했다.
- 그 밖의 개발·언어·Markdown 지침과 프로젝트 코드 언어 정책은 작업 계약이나 예외에 필요해 유지했다.

제품 동작은 변경하지 않는다. 선택한 주요 계약과 상대 링크를 검증했으며 실제 결과는 [작업 기록](../tasks/1794055365326.md)에 남겼다.
