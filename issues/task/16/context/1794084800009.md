# PR 리뷰 후속 수정 적용 판단

## 상황과 근거

사용자는 세 프로젝트에서 합의한 두 수정을 csvd2c의 기존 `task/16`에도 적용하도록 요청했다. 현재 PR 생성기와 릴리즈 수집 단계는 수정 전 공통 코드와 같으며 기존 이슈 #16은 종료 상태다.

## 결정과 영향

이미 검증한 공통 수정과 테스트를 같은 방식으로 적용한다. 공백 1~3칸으로 들여쓴 마지막 마커를 오류로 처리하고 변경 로그를 읽기 전에 일반 파일인지 검사한다. 네 칸 이상·탭 들여쓰기의 기존 폴백과 그 한계, 파일 3,000개 제한과 App 권한 구조는 유지한다. 원격 이슈 상태는 변경하지 않는다. 구현과 검증은 아직 진행 전이다.
