# 지침 정리의 상황과 판단

## 상황과 목표

사용자가 CLI·원격 에이전트에 맞는 지침 정리와 이슈 유무에 관계없는 공통 작업 기록을 요청했다. 현재 세부 지침은 이슈 중심으로 작성되어 있고 원격 플랫폼의 브랜치·PR 흐름과 충돌한다.

## 근거와 결정

- `AGENTS.md`는 이슈가 없는 작업을 `tasks/<UNIX_TIMESTAMP>/`에 기록하도록 안내한다. 이 요청은 특정 이슈에 연결되지 않아 그 위치를 사용한다.
- `.instructions/TASK.instructions.md`는 이슈 기록을 필수로 요구하지만 비이슈 작업에는 적용되지 않는다. 사용자의 결정에 따라 요구사항·계획·변경 로그와 단계별 기록을 양쪽에 공통으로 적용한다.
- `.instructions/INSTRUCTIONS.instructions.md`는 지침 위치를 `instructions/`로 설명하지만 실제 위치는 `.instructions/`다.
- `.instructions/README.instructions.md`와 `.instructions/DOCS.instructions.md`의 브로커 관련 지침은 `README.md`와 `setup.py`에서 확인한 csvd2c의 CSV 정제 기능 및 빈 `extras_require`와 맞지 않는다.
- 커밋 메시지의 트레일러 문구와 예시가 어긋나지만 사용자가 원하는 트레일러 정책은 확정되지 않았다. 정책을 추측하지 않고 해당 불일치를 남긴다.

## 영향과 검증

제품 동작은 변경하지 않는다. 지침 변경과 검증 결과는 후속 작업 기록에 남긴다.
