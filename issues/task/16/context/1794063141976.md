# IR 문서의 이슈 연결과 변경 로그 항목

## 상황과 근거

사용자는 `IR.md`에 `Closes`와 `Changes:`가 빠진 점을 지적했다. 이전 구현은 이를 문서에 넣지 않고 자동화에서 PR 본문에만 추가했다. 그 결과 로컬 문서만 보면 이슈 연결과 변경 로그 경로가 보이지 않았다.

## 결정과 영향

csvd2c의 `IR.md`에 두 항목을 직접 기록하고 자동화는 해당 이슈와 경로에 일치하는 마지막 항목을 검증해 중복 없이 그대로 사용한다. 공통 지침에는 플랫폼과 프로젝트의 이슈 연결·변경 로그 규칙을 따라 문서에 기록하도록 안내한다.

기존 `IR.md`에도 두 항목을 작성해야 하며 누락되거나 다른 이슈·경로를 가리키면 자동화가 오류로 중단된다. 실제 원격 시스템 변경은 수행하지 않는다.

관련 Node 테스트 70개와 현재 이슈 문서의 항목이 PR 본문에 중복 없이 반영되는 결과를 로컬에서 확인했다.
