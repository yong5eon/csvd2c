# PR 본문과 생성 조건 변경

## 상황과 결정

[사용자 결정](./1794057178467.md)에 따라 새 PR의 변경 로그는 필수이고 기존 PR 본문은 유지한다. 자동 생성 함수에서 변경 로그 내용을 확인하고 `buildPullRequest`가 이슈 종료 구문 뒤에 경로를 작성한다. 이미 열린 PR을 처리하는 기존 분기는 변경하지 않는다.

본문을 줄이는 기존 대체 경로도 같은 렌더링을 사용하므로 마지막 두 항목을 렌더링 단계에서 추가한다. 테스트는 실제 생성 요청 전의 누락·공백 차단과 본문 길이 경계를 확인한다. CI 수집이나 실제 GitHub의 PR은 변경하지 않는다.

관련 테스트에서 마지막 항목과 길이 경계, 누락·공백 차단 및 기존 PR 본문 보존을 모의 GitHub 응답으로 확인했다. 실행 결과는 [작업 기록](../tasks/1794057212842.md)에 남겼다.
