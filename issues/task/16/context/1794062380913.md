# PR 문서 제목 연동 판단

## 상황과 근거

사용자는 `PR.md`에 작성한 제목도 PR 제목으로 사용하도록 요청했다. 이전 구현은 본문만 `PR.md`에서 가져오고 제목은 이슈 README 또는 원본 이슈에서 가져왔다.

## 결정과 영향

`PR.md` 첫 줄의 Markdown 최상위 제목을 PR 제목으로 사용하고 나머지 내용을 본문으로 사용한다. 제목이 본문에 중복 표시되지 않으며 제목이나 본문이 없거나 제목이 256자를 넘으면 원격 쓰기 전에 실패한다. 이전의 제목 선택 방식은 이 결정으로 대체한다.

기존 `PR.md`에도 첫 줄 제목이 필요하다. 나머지 PR 생성·갱신과 footer 처리는 유지하며, 실제 GitHub Actions는 실행하지 않는다.

관련 Node 테스트 63개와 현재 이슈 문서의 제목·본문·footer 조합을 로컬에서 확인했다.
