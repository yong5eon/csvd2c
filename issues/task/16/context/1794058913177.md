# 이슈 브랜치의 새 PR을 Draft로 생성

## 상황과 근거

사용자가 이슈 브랜치 자동 생성 PR은 Draft로 시작하도록 요청했다. 워크플로는 `.github/scripts/create-pr-from-issue.mjs`를 실행하고, `createPullRequest`는 기존 열린 PR을 먼저 확인한 뒤 없을 때 GitHub REST API로 새 PR을 생성한다.

[GitHub의 PR 생성 API 문서](https://docs.github.com/en/rest/pulls/pulls#create-a-pull-request)는 요청 본문의 `draft` 불리언으로 Draft 여부를 지정하도록 설명한다. 현재 생성 요청에는 이 값이 없다.

## 결정과 영향

새 PR 생성 요청에 `draft: true`를 추가한다. 기존 열린 PR은 상태와 본문을 그대로 유지하며 자동으로 일반 PR로 전환하지 않는다. 관련 테스트는 실제 HTTP 요청 대신 모의 응답을 사용하므로 GitHub의 실제 실행 결과는 별도로 확인해야 한다.

새 PR 요청과 기존 열린 PR 처리의 관련 테스트 2개가 통과했다. 자동화 변경은 csvd2c의 공개 API·설치·사용법이 아니므로 상세 매뉴얼과 루트 README의 변경은 불필요하다.
