# 검수·문서 영향·계획 지침 보완 근거

## 상황과 결정

[요구사항과 계획](../PLAN.md#후속-작업-8의-변경검증-계획)에 따라 세 지침의 적용 경계를 명확히 했다. 앞선 조사와 원복 정정은 [이전 근거 기록](./1794056217714.md)에 남겼다.

- 단순 의견과 자료 검수는 필요한 조회 여부가 다르므로 구분한다. 검수의 읽기 전용 확인은 허용하되 수정이나 테스트 실행 권한까지 추정하지 않는다.
- 코드 변경에서 상세 매뉴얼의 완료 전 영향 검토가 누락되지 않도록 진입 지침에서 매뉴얼·루트 README 지침을 직접 연결한다. 실제 영향에 따라 갱신하거나 불필요한 이유를 기록한다.
- 계획의 대상과 역할은 모든 작업에 필요하지만 코드 구성요소는 해당할 때만 필요하다. 필수 문서나 코드 작업에 필요한 구체성은 유지한다.

상세 매뉴얼의 사용자가 원복한 한·영 규칙은 변경하지 않았다. 검증 결과는 [작업 기록](../tasks/1794056252358.md)에 남긴다.
