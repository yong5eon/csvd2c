# AI 기반 PR 본문 작성 조사

## 상황과 근거

기존 PR 자동화는 작업 문서의 전문을 템플릿에 넣는다. 사용자는 푸시 시 AI가 기존 작업 내용을 바탕으로 템플릿에 맞는 간결한 본문을 작성하기를 요청했으며, 별도의 `PR.md`나 에이전트 작성 지침은 원하지 않는다고 밝혔다.

에이전트가 별도 문서를 작성하는 방식을 이미 정해진 동작처럼 설명하고 누락 처리부터 반복해서 질문했다. 실제 지침과 사용자의 의도에 없는 전제였으며, 사용자 설명 후 해당 접근을 중단했다.

## 해석과 결정

기존 리뷰 처리 자동화는 Copilot CLI를 도구 없이 실행하지만 명시적인 `--model` 옵션이 없다. 따라서 저장소 코드만으로 실제 선택 모델을 확인할 수 없다.

[GitHub의 코드 리뷰 수준 설명](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available/)에 따르면 Lite와 Balanced는 코드 리뷰의 수행 수준이다. [Copilot CLI 문서](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/choose-a-model)는 별도의 `--model` 선택을 설명한다. 리뷰 수준과 CLI 모델을 동일하게 가정하지 않고 모델 선택을 확인한다.

## 영향과 남은 사항

PR 본문 생성과 리뷰 처리 코드는 아직 변경하지 않았다. 자동화에 사용할 모델과 실제 Actions 권한·사용 가능 여부가 확인되지 않았으며, 구현 전 입력 범위와 오류 처리도 계획해야 한다.
