# CI 변경 로그 경로 구현과 검증

## 상황과 결정

[분석과 계획](./1794057585965.md)에 따라 실제 워크플로의 수집 코드를 그대로 실행하는 모의 테스트를 준비한다. `Changes:`가 가리키는 경로는 허용된 작업 기록 디렉터리로 한정하고 중복이나 잘못된 항목은 기존 경로로 폴백하지 않는다.

PR 본문에 포함된 `<details>` 문서, 코드 펜스, 들여쓰기 코드와 HTML 주석은 실제 변경 로그 항목이 아니므로 구분한다. 주석과 들여쓰기 예시를 추가한 테스트에서 실제 항목과 중복으로 오인하는 실패를 확인해 해당 구분을 보강했다. 기존 경로, 직접 push, 릴리즈 노트 재사용과 Git 파일 검증은 유지한다. 외부 GitHub 호출과 Git 명령은 테스트에서 모의 처리하므로 실제 GitHub Actions 환경은 별도 검증이 필요하다.
