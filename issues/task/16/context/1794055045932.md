# 공통 지침과 프로젝트 지침 분리

## 상황과 근거

사용자가 여러 프로젝트를 함께 다루는 작업 환경에서 공통 에이전트 지침과 csvd2c 전용 지침을 구분하기 위해 공통 지침을 `.instructions.assistant/`로 이동하도록 요청했다. 현재 두 종류의 지침은 `.instructions/`에 함께 있고 `AGENTS.md`도 그 위치만 안내한다.

`.github/instructions`는 `.instructions/`를 가리키는 기존 로컬 junction이다. 공통 지침을 이동해도 이 연결은 프로젝트 전용 지침을 가리키며, 이동한 공통 지침이 해당 경로를 통해 자동 적용된다고 가정할 수 없다.

## 결정과 영향

`DEV*`, `GIT.COMMIT*`, `INSTRUCTIONS`, `MARKDOWN`, `TASK` 지침만 공통 디렉터리로 이동하고 `CODE`, `DOCS`, `README`는 프로젝트 지침 위치에 둔다. `AGENTS.md`와 지침 간 참조를 실제 위치에 맞게 고친다. 기존 junction과 IDE 설정은 변경하지 않으며, 공통 지침은 에이전트가 진입 문서의 안내에 따라 직접 읽는다.

## 검증

이동 전 지침 목록, 대상 디렉터리 부재, 브랜치와 기존 junction을 확인했다. 이동 후 공통 지침 7개와 프로젝트 지침 3개의 구성, 상대 링크·앵커 13개 및 junction 대상을 확인했다. Python 지침의 프로젝트 전용 링크는 공통 언어 규칙과 프로젝트 예외를 따르는 설명으로 바꾸어 위치 변경 후에도 csvd2c의 영어 정책을 유지했다.
