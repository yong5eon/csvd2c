# 단계별 기록의 사후 변경 방지

## 상황과 근거

사용자가 과거 기록을 후속 작업에 맞춰 바꾸는 것이 적절한지 지적했다. 에이전트는 완료된 [이전 구현 기록](../implements/1794057719626.md)에 후속 구현 링크를 추가했다. 당시 사실을 지우지는 않았지만 새 기록에서 이전 기록을 연결하면 충분했다.

기존 작업 지침은 기록의 삭제·대체를 금지하고 새 기록에서 정정하도록 하지만, 완료된 기록에 내용을 추가하는 경우까지 명시하지 않는다.

## 결정과 영향

완료·중단된 단계별 기록은 보존하고 후속 정정이나 연결은 새 작업 단위에서 작성한다. 동일 작업 단위가 진행 중일 때의 기록 갱신과 현재 상태·종합 문서 갱신은 허용한다. 승인된 민감정보·개인 경로 정리 규칙은 그대로 유지한다.

사용자는 csvd2c에만 작업 기록을 남기고, 개인 관리용 Instructions는 `master`에서 별도 기록 없이 변경하도록 결정했다. 이미 추가한 과거 기록의 링크는 다시 수정하지 않고 이 기록에서 당시 행위와 판단을 남긴다.

두 지침에 같은 원칙을 반영하고 해당 문단이 일치하는지 확인했다. 문서 변경이므로 제품 테스트는 실행하지 않았다.
