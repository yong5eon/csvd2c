# 지침 검증과 남은 결정

## 상황과 근거

변경된 지침의 공통 필수 문서, 이슈·비이슈 기록 위치, 원격 브랜치와 PR 경로, 미확정 사항 처리, 상대 링크를 확인했다.

첫 검증에서는 기본 Python 환경의 기존 패키지 초기화 오류와 파이프 인코딩 문제로 검사 결과가 신뢰할 수 없었고, 커밋 메시지 지침의 존재하지 않는 작업공간 설정 파일 링크도 확인했다.

## 결정과 결과

- 기존 사용자 환경을 변경하지 않고 `python -S`와 UTF-8 파이프로 검증을 다시 실행해 문서 15개, 상대 링크 22개, 공통 계약 6개를 확인했다.
- 존재하지 않는 설정 파일을 링크하는 대신 VS Code 설정 위치를 안내하도록 정리했다.
- 커밋 메시지 지침은 기본 트레일러 미포함 규칙과 트레일러가 있는 예시가 공존한다. 의도를 확인하기 전 어느 쪽도 임의로 정책으로 확정하지 않는다.
- 이슈 작업의 PR 경로 표기는 정리했지만 CI는 이 작업의 범위에 포함하지 않았다.
