# 커밋 메시지 지침의 범위 정리

## 상황과 근거

사용자가 커밋 메시지 지침의 VS Code 전용 설정이 필요한지 확인하고 불필요한 내용을 검토해 제거하도록 요청했다. 해당 문서는 CLI·원격 에이전트가 메시지를 작성할 때 읽는 지침이다.

## 결정과 영향

메시지 작성 규칙과 무관한 VS Code 설정 절을 삭제했다. 커밋·푸시 권한은 공통 지침에서 관리하므로 이 문서의 중복 설명을 제거했고, 트레일러 형식은 전체 메시지 예시에도 나타나므로 별도의 형식 블록을 삭제했다. 제목·본문·이슈 참조와 단독·공동 기여자에 관한 규칙은 유지했다.

VS Code 설정 파일과 사용자 설정은 변경하지 않았다. 제품 동작에도 영향이 없다.
