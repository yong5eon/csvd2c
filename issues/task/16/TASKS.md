# 작업 결과

GitHub 이슈 #16을 `task` 레이블로 등록하고, `master`를 기준으로 `task/16` 브랜치를 준비했다. 공통 지침 원본, csvd2c 프로젝트별 지침과 CI의 이슈별 changelog 경로를 확인했다. 검증 내역은 단계별 작업 기록에 남겼다.

이후 사용자의 요청에 따라 CLI·원격 에이전트용 통합 지침과 이슈 유무에 공통인 작업 기록을 정리했다. 이 과정을 에이전트가 비이슈 작업으로 잘못 분류한 사실을 사용자가 지적해, 기존 기록을 보존하면서 이슈 #16 기록으로 옮겼다. 상세한 판단과 정정은 [후속 판단 기록](./context/1794054298792.md)에 남겼다.

단독 커밋에는 작성자 본인을 공동 기여자로 기재하지 않고, 실제 공동 기여자가 있는 경우 확인된 기여자를 기재하도록 지침을 정리했다. 관련 문서와 상대 링크 및 정정 계약을 확인했다. 실제 GitHub 에이전트 세션 검증은 미완료다.

비이슈 작업도 사용자 요청을 `README.md`에 먼저 기록하고 조사·분석 결과로 보강하도록 작업 지침을 명확히 했다. 조사·분석은 이슈 유무와 관계없이 실제 작업마다 필요한 범위에서 수행한다.

공통 에이전트 지침은 `.instructions.assistant/`로 옮기고 csvd2c 전용 지침은 `.instructions/`에 유지했다. `AGENTS.md`와 탐색 안내를 갱신하고 파일 구성·상대 링크·기존 junction을 확인했다. IDE의 공통 지침 자동 로딩은 검증하지 않았다.

커밋 메시지 지침에서 VS Code 전용 설정과 중복 설명을 제거하고 메시지 작성에 필요한 규칙을 유지했다.

다른 공통·프로젝트 지침도 검토해 중복된 예시와 설명, 현재 프로젝트에 맞지 않는 항목을 정리했다. 필수 작업 기록, 언어 예외와 문서 동기화 등 주요 계약 및 상대 링크를 확인했다.

이후 사용자가 상세 매뉴얼의 한·영 동시 갱신 문장을 원복했으며, 에이전트의 잘못된 설명은 [후속 근거 기록](./context/1794056217714.md)에 정정했다. 검수의 읽기 전용 권한, 코드 변경의 문서 영향 검토와 작업별 계획 작성 범위를 명확히 했다. 관련 인수 기준과 문서 연결을 확인했다.

PR 자동 생성 변경에 앞서 기존 본문 생성과 문서 누락 처리를 확인하고 사용자에게 처리 방식을 결정받았다. 모의 GitHub 응답을 사용하는 관련 테스트 61개가 통과했다. 자동화 작업은 csvd2c의 공개 API·설치·사용법이 아니므로 상세 매뉴얼과 루트 README의 변경은 불필요하다.

CI의 PR 변경 로그 경로 수집은 실제 워크플로 코드를 실행하는 모의 테스트 7개와 YAML 구문을 로컬에서 확인했다. 상세 매뉴얼과 루트 README는 제품 API·설치·사용법을 설명하므로 갱신하지 않았다. 실제 GitHub Actions 실행과 배포는 확인하지 않았다.

사용자 요청에 따라 테스트 파일은 유지하고 CI 실행 단계를 제거했다. YAML 구문과 남은 수집 단계, 테스트 파일 존재를 확인했다.

완료·중단된 단계별 기록을 후속 작업에 맞춰 수정하지 않고 새 기록에서 정정·연결하도록 csvd2c와 Instructions의 작업 지침을 명확히 했다. 진행 중 기록, 상태·종합 문서와 승인된 정리 예외는 구분했다.

이슈 브랜치에서 새로 생성하는 PR의 Draft 적용을 검증했다. 모의 GitHub 응답을 사용하는 새 PR 생성과 기존 열린 PR 유지 테스트 2개가 통과했으며 실제 GitHub PR 생성은 실행하지 않았다.

기존 PR의 제목·본문 갱신 범위와 수동 편집 덮어쓰기, 변경 로그 오류 처리를 사용자에게 확인했다. PR 자동화 관련 테스트 64개가 통과했으며 실제 GitHub PR 갱신은 실행하지 않았다.
