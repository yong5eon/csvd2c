# 에이전트 작업 지침과 PR 자동화 연동

## 변경 내용

- CLI와 원격 에이전트가 공통·프로젝트 지침을 찾고 이슈 작업의 근거와 실행 기록을 남기도록 정리했습니다.
- GitHub PR과 GitLab MR에서 사용할 `IR.md` 형식을 공통 지침에 명시했습니다.
- 이슈 브랜치의 새 PR은 Draft로 생성하고, 푸시할 때 작업 디렉터리의 `IR.md`로 PR 제목과 본문을 갱신합니다.
- `copilot/**`, `codex/**` 브랜치에서는 열린 PR의 변경 파일에서 이슈 `IR.md`를 찾아 제목과 본문을 갱신합니다.
- 해결한 여러 이슈를 각각 `Closes`로 지정할 수 있으며, 변경 로그 경로는 비어 있지 않은 마지막 줄만 검사합니다.
- 이슈·비이슈 PR의 마지막 `Changes:` 경로를 릴리즈 변경 로그 수집에 사용하고, 해당 항목이 없으면 기존 브랜치 경로를 유지합니다.
- 들여쓴 `Changes:` 마커의 형식과 변경 로그의 일반 파일 여부를 검사합니다.
