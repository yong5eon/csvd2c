````markdown
## 배경

긴 문자열이 포함된 CSV를 읽을 때 Python CSV 파서의 필드 크기 제한 때문에 다음 오류가 발생할 수 있습니다.

```text
field larger than field limit (131072)
```

## 요청 사항

- `CSV` 생성자를 통해 CSV 필드 크기 제한을 설정하고, 기본 제한보다 큰 필드도 읽을 수 있도록 지원합니다.
- 기존 생성자 사용 방식과 기본 동작을 유지합니다.
- 설정값의 허용 범위와 잘못된 값의 오류 처리, Python `csv.field_size_limit()`의 전역 설정으로 인한 영향을 검토하고 사용 방법과 제약을 문서화합니다.
- 기본 제한을 초과하는 필드의 읽기와 설정된 제한을 초과하는 경우를 포함해 테스트합니다.

최대 설정 가능 값은 Python과 플랫폼에 따라 다를 수 있으며, 실제 처리 가능 크기는 사용 가능한 메모리에도 영향을 받습니다.

## 최대값 참고

- `sys.maxsize`는 Python에서 인덱스와 크기에 사용하는 정수의 최대값이며, 64비트 환경에서는 보통 `9_223_372_036_854_775_807`입니다. `csv.field_size_limit(sys.maxsize)`를 시도할 수 있지만, Python 버전과 플랫폼에 따라 `OverflowError`가 발생할 수 있습니다.
- `sys.maxsize`가 허용되지 않는 환경에서는 `2_147_483_647`처럼 더 작은 값을 설정할 수 있습니다. 이 값도 해당 환경의 허용 범위와 메모리 제약을 확인해야 합니다.
- 제한은 바이트가 아닌 CSV 필드의 문자 수입니다. 설정 가능한 최대값과 실제 메모리에서 처리 가능한 크기는 다릅니다.
````
