# 구현 전 기준 동작 확인

- [근거와 결정](../context/1794044372545.md)에 따라 브랜치·지침·검증 환경을 확인했다.
- Windows 64비트 CPython 3.12.10의 기존 editable 환경에서 `python -m unittest discover -s tests -p test_csv.py -v`를 실행하여 36개가 통과했다.
- VS Code 선택 interpreter의 집중 실행으로 `CSV().open()`과 `row()`에서 `131073`문자 필드가 `csv.Error: field larger than field limit (131072)`를 발생시키는 것을 확인했다. 전역 제한은 원래 값으로 복원했다.
- 기존 빌드 도구 `build`는 설치되어 있지 않다. 현재 작업 소스의 기능 검증을 먼저 수행하고 배포본 검증은 기존 setuptools 빌드 절차의 사용 가능 여부를 확인한다.
- 편집 후 이전 editable 빌드의 `CSV.py`에 새 상수가 없어 `ImportError`가 발생했다. 이는 기존 연결의 stale 상태이며, 공유 환경을 재설치하지 않고 이번 소스를 wheel로 빌드해 별도 검증 환경에 설치했다.
- `python -m pip wheel --no-deps --no-build-isolation --no-cache-dir . --wheel-dir <검증용 출력>`로 wheel 빌드에 성공했다. 새 검증 환경은 `venv --without-pip`로 만들고 기존 pip의 `--python` 옵션으로 로컬 wheel만 설치했다.
- Windows CPython 3.12.10의 설치 wheel에서 CSV 테스트 47개가 통과했다. 새 상수값과 생성자 시그니처도 실제 import로 확인했다.
- Pylance 생성자 호출 호환성 검사는 호출 지점을 찾지 못했다. 이를 호환성 통과로 간주하지 않고, 실제 import의 시그니처·기존 테스트로 확인했다.
