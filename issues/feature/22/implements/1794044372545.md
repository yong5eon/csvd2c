# 공개 상수와 선택적 필드 제한 구현

[구현 결정](../context/1794044372545.md)에 따라 다음을 변경했다.

- `src/CSV.py`에 `MAX_FIELD_SIZE: int = 2_147_483_647`을 정의하고 `src/__init__.py`에서 패키지 공개 상수로 재노출했다.
- `CSV.__init__()` 마지막에 `field_size_limit: Optional[int] = None`을 추가했다. 기존 인자 검증·초기화 후 타입·범위를 검사하고, 값이 있을 때만 표준 설정을 호출한다.
- `bool` 등 잘못된 타입은 `TypeError`, 음수·상수 초과는 `ValueError`로 처리한다. 표준 함수 실패는 그대로 전파한다.
- 인스턴스 상태·읽기·종료 경로는 변경하지 않았다. 따라서 이미 열린 reader도 전역 설정의 영향을 받으며, 자동 복원하지 않는다.
- `tests/test_csv.py`에 공개 API, 입력 검증, 경계값, 헤더·offset·읽기 모드, 전역 영향·복원 없음의 테스트 11개를 추가했다. 잘못된 타입을 의도적으로 넣는 테스트만 기존 패턴의 `type: ignore[arg-type]`을 사용했다.
- 생성자 독스트링은 프로젝트 예외 지침에 따라 영어로 갱신했다.
