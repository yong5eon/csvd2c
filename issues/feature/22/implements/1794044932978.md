# 매뉴얼 반영과 테스트 호환성 수정

[검증 판단](../context/1794044932978.md)에 따라 다음을 반영했다.

- `docs/README.md`와 영어판에 필드 크기 제한 절·목차, 생성자 설정과 `MAX_FIELD_SIZE` 예제, 허용 범위·문자 수 경계·오류 계약을 추가했다.
- 같은 인터프리터의 reader가 공유하는 설정이며 종료 후 복원되지 않는다는 점, 호출자의 `try/finally` 복원이 독립적인 동시 제한을 보장하지 않는다는 점을 설명했다.
- 큰 제한은 메모리를 선할당하지 않지만 실제 필드의 메모리 부족을 막지 못한다는 제약을 추가했다. 루트 한국어·영어 README에는 핵심 요약과 상세 매뉴얼 연결만 반영했다.
- 새 테스트의 mock 대상을 `sys.modules`의 실제 CSV 모듈로 지정하여 Python 3.10~3.14의 이름 해석 차이를 제거했다. 제품 API나 설정 동작은 변경하지 않았다.

검증은 [작업 기록](../tasks/1794044932978.md)에 정리했다. 요구사항·계획 상태와 종합 기록을 갱신하고 고객용 변경 로그를 작성한다.
