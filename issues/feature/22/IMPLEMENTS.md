# 필드 크기 제한 구현 결과

## 변경과 계약

[요구사항 R1~R5](./REQUIREMENTS.md)를 반영했다.

- [CSV 생성자](../../../src/CSV.py)에 `field_size_limit: Optional[int] = None`을 추가했다. 기존 검증·초기화가 모두 성공한 뒤 값이 지정된 경우에만 표준 CSV 전역 제한을 설정한다.
- `None`은 현재 값을 유지한다. 정수 `0`부터 `2_147_483_647`까지 허용하며, 잘못된 타입은 `TypeError`, 음수·최대값 초과는 `ValueError`다. 표준 함수 오류는 그대로 전파한다.
- [패키지 공개 API](../../../src/__init__.py)에 `MAX_FIELD_SIZE`를 재노출하여 `from csvd2c import MAX_FIELD_SIZE`를 지원한다.
- 기존 읽기·헤더·offset·검증·종료 경로를 유지했다. 설정은 다른 reader에도 적용되며, 자동 재적용이나 복원은 없다. 읽는 필드의 초과 오류는 표준 `csv.Error`다.
- [CSV 테스트](../../../tests/test_csv.py)에 11개 테스트를 추가하고 한국어·영어 매뉴얼과 루트 README를 갱신했다.

검증과 환경별 제한은 [작업 종합](./TASKS.md)을 따른다. 로컬 구현 완료이며 커밋·푸시·병합·배포는 수행하지 않았다.
