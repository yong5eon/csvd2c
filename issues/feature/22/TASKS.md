# 필드 크기 제한 작업·검증 결과

- Windows 64비트 CPython 3.12.10에서 변경 전 CSV 테스트 36개가 통과했고, 기본 제한을 초과하는 `131073`문자 필드의 실패를 재현했다.
- 독립 환경에 설치한 이번 소스의 wheel로 Python 3.10.11·3.12.10·3.14.5의 전체 테스트 각각 190개가 통과했다. mock 호환성 수정 후 3.12·3.14의 CSV 테스트 47개도 다시 통과했다.
- 한국어·영어 매뉴얼 예제의 실제 출력과 전역 제한 복원을 확인했다.
- 입력 경계·공개 API·전역 부작용·파서 오류 및 기존 자원 관리 계약은 해당 테스트로 확인했다.
- Linux·Python 3.11·3.13 및 원격 CI는 미실행이다. 기존 선택 환경의 stale editable import와 Pylance 테스트 진단 때문에 전체 정적 검사 통과로 보고하지 않는다. 필요하면 해당 개발 환경의 editable 설치를 갱신한다.
- 커밋·푸시·병합·이슈 변경·배포는 수행하지 않았다.
