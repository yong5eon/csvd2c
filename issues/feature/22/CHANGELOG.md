# CSV 필드 크기 제한 설정 지원

## 큰 필드 읽기

기존에는 큰 필드를 읽으려면 호출자가 Python 표준 CSV 전역 설정을 직접 변경해야 했습니다. 이제 `CSV(field_size_limit=...)`으로 필요한 문자 수 제한을 지정할 수 있습니다. 생략하거나 `None`을 지정하면 현재 제한을 유지하므로 기존 호출은 바꿀 필요가 없습니다.

`from csvd2c import MAX_FIELD_SIZE`로 최대 설정값 `2_147_483_647`을 가져올 수 있습니다. 실제 예상 필드 길이에 맞는 제한을 권장합니다.

## 오류와 주의사항

- 허용 범위는 정수 `0`부터 `MAX_FIELD_SIZE`까지입니다. 음수·최대값 초과는 `ValueError`, `bool` 등 잘못된 타입은 `TypeError`입니다.
- `0`은 빈 필드만 허용합니다. 필드는 바이트가 아닌 문자 수로 제한하며, 실제 읽기에서 초과하면 표준 `csv.Error`가 발생합니다.
- 설정은 기존 reader와 다른 `CSV` 인스턴스에도 영향을 주는 전역값입니다. 파일을 닫아도 자동 복원하지 않습니다.
- 최대값은 메모리 안전이나 최대 길이 필드의 실제 처리 가능성을 보장하지 않습니다.

사용 예제와 호출자 복원 방법은 [필드 크기 제한 매뉴얼](../../../docs/README.md#필드-크기-제한)을 참고하세요.
