# 원문 조회 API와 읽기 경계 상태 관리 구현

`src/CSV.py`에 `raw_data: Optional[List[str]]`와 `raw() -> Optional[List[str]]`를 추가했다.

- `read_record()` 진입 시 이전 원문을 비워 limit 도달·EOF·offset 및 데이터 파싱·디코딩 실패에서 오래된 원문이 남지 않게 했다.
- 범위 안 데이터 레코드를 읽으면 즉시 얕은 복사본을 저장한다. 이후 행 Pattern이 목록을 바꾸거나 컬럼 검증이 제자리에서 값을 변경해도 원문은 유지된다.
- `raw()`는 `None`을 명시적으로 구분하고 매번 복사본을 반환한다. 유효한 빈 레코드 `[]`는 그대로 보존한다.
- 생성·open·close에서 원문 상태를 초기화한다. close의 기존 `finally`에서 정리하므로 스트림 종료 오류도 숨기지 않는다.
- 헤더 경로·검증 함수·오류 클래스·Pattern 시그니처는 변경하지 않았다. `row()`와 `iterate()`의 공통 읽기 함수를 활용해 중복 구현을 피했다.
