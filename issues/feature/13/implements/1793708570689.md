# 원문 조회 사용 문서와 거부 기록 예시 반영

- 한국어·영어 상세 매뉴얼에 `raw()`의 반환형과 상태 표, `rows()` 생성·정상 소진·검증 예외의 차이, 열린 컨텍스트 안에서 실패 원문을 조회해야 하는 제약을 추가했다.
- 오류 객체는 실패 Pattern 입력을 유지하고 CSV가 검증 전 전체 필드를 보존한다는 차이를 설명했다. 검증 흐름도에도 원문 복사 시점을 반영했다.
- 임시 합성 TSV의 실패 레코드를 같은 delimiter·escapechar 설정의 writer로 저장하고 재파싱하는 실행 예시를 추가했다.
- 기존 `samples/reject_records.py`는 오류의 `value` 외에 `raw` 필드를 JSONL에 추가한다. 공백 필드의 컬럼 실패를 추가해 오류 값은 빈 문자열이지만 원문 공백은 유지되는지 확인한다.
- 루트 README와 샘플 안내의 한국어·영어판을 함께 갱신했다. 샘플 개수는 기존 24개를 유지했다.

핵심 및 샘플 회귀 결과는 [검증 기록](../tasks/1793708570688.md)에 정리했다. 문서 예시와 최종 형식 검증은 이어서 수행한다.
