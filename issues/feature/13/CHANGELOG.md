# 검증 전 원문 레코드 조회 지원

## 실패한 레코드의 전체 필드 보관

`CSV.raw()`로 마지막 데이터 레코드의 검증 전 필드를 조회할 수 있습니다. 앞선 행·컬럼 Pattern이 값을 바꾸거나 검증에 실패했어도 최초 필드 목록을 얻어 저장하고, 수정 후 같은 검증에 다시 사용할 수 있습니다.

- 반환형은 `Optional[List[str]]`이며 매번 복사본을 반환합니다.
- `row()`·`rows()`의 성공·검증 실패 레코드를 보존합니다. 헤더와 offset으로 건너뛴 레코드는 제외합니다.
- 데이터 읽기 전, 다음 읽기가 EOF·limit·파싱·디코딩 오류로 끝난 경우, 파일 종료·재open 후에는 `None`입니다.
- 실패 후에도 처리하려면 열린 컨텍스트 안에서 `row()`의 검증 오류를 잡고 `raw()`를 저장한 뒤 다음 `row()`를 호출하세요. 예외로 종료된 동일 `rows()` generator는 재개할 수 없습니다.

원문은 파일의 줄 텍스트나 바이트가 아닌 파싱된 필드 목록입니다. 같은 CSV 설정으로 다시 쓰면 필드 값은 보존되지만 따옴표·escape 표기는 달라질 수 있습니다. 기존 오류의 `value`와 Pattern 시그니처는 변경하지 않습니다.

## Python 3.10 이상 필요

Python 3.9의 표준 `csv.writer`에서 필드 내 escape 문자가 손실되는 문제를 피하기 위해 최소 지원 버전을 3.10으로 높였습니다. 기존 Python 3.9 환경은 업그레이드 후 사용하세요. 별도 CSV 데이터·설정 마이그레이션은 필요하지 않습니다.
