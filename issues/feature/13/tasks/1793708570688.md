# 원문 조회와 관련 회귀 테스트 검증

- 핵심 구현 후 `python -m unittest discover -s tests -p test_raw.py` 실행 결과 15개 테스트가 통과했다.
- 작업공간 가상환경에서 격리 모드(`python -I`)로 import한 패키지가 이 작업 트리의 `src/__init__.py`임을 확인했다.
- 저장소 루트에서 `tests`를 모듈 검색 경로로 지정하고 `python -m unittest test_raw test_csv test_range test_header test_error_context test_samples`를 실행했다. 109개 테스트가 통과했으며 샘플 테스트는 독립 프로세스에서 기존 샘플 24개를 실행했다.
- 변경 전후 `src/CSV.py`의 Pylance 진단은 없었다. 테스트 분석에서는 `raw` 접근 오류(`reportAttributeAccessIssue`)와 기존 `offset`·`limit` 인자 오류(`reportCallIssue`)가 나타났다. 수정하지 않은 `test_range.py`에서도 같은 인자 오류가 발생했다.
- Pylance의 선택 인터프리터는 테스트에 사용한 작업공간 가상환경과 같았지만 정의 조회 도구는 내부 오류로 실패했다. 런타임은 editable import로 현재 소스를 사용한다. 분석기의 실제 참조 차이는 확정하지 못했으며 사용자 설정과 설치된 프로젝트 패키지는 변경하지 않았다.
- 사용 가능한 Pyright가 없어 일회성 실행 도구로 확보했다. 저장소 밖 임시 분석 경로에서 패키지 이름을 현재 `src`에 연결하고 변경 Python 파일 3개를 명시해 Python 3.9·basic 타입 검사를 실행했다. 오류·경고·정보 모두 0건이었다. 초기 설정의 절대 include 경로가 무시된 시도는 유효한 검증 결과에서 제외했다.

임시 분석 경로·설정은 검증 종료 후 정리한다. 다음 작업은 문서 예시 실제 실행, 최종 변경 검토와 종합 기록이다.
