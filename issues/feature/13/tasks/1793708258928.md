# 원문 계약 테스트의 구현 전 실패 확인

- 현재 작업 브랜치와 기존 명세·계획·기록, Python 및 Markdown 지침을 확인했다.
- 변경 전 `src/CSV.py`의 Pylance 진단은 없었다.
- `tests/test_raw.py`에 A1~A11과 공개 반환 시그니처를 확인하는 테스트 15개를 작성했다. 읽기 모드·검증 실패·디코딩 버퍼·동일 generator 종료 등은 하위 사례로 구분했다.
- Pylance 구문 검사에서 테스트 파일의 구문 오류는 없었다.
- 저장소 루트에서 작업공간 가상환경의 `python -m unittest discover -s tests -p test_raw.py`를 실행했다.
- 구현 전 결과는 15개 테스트, 하위 사례 포함 오류 34건이었다. `CSV.raw` 부재에 따른 `AttributeError`를 확인했다.

다음 단계는 공통 데이터 읽기 경계와 생명주기에 원문 상태를 추가하고 같은 테스트를 재실행하는 것이다.
