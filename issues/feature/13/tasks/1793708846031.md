# Python 3.9 표준 writer 제약 확인과 최소 버전 변경 승인

- Python 3.9.13에서 신규 테스트 15개 중 escape 문자 왕복 1개가 실패했다. `raw()`의 원문은 정확했지만 표준 writer→reader 왕복에서 역슬래시가 사라졌다.
- csvd2c를 제외하고 표준 `csv.writer`와 `csv.reader`만 사용한 동일 필드의 왕복도 Python 3.9.13에서는 실패하고 3.10.11에서는 통과했다.
- [CPython 오류 #56387](https://github.com/python/cpython/issues/56387)에서 표준 writer의 escape 문자 처리 수정이 Python 3.10에 반영된 것을 확인했다.
- 사용자에게 3.9 지원 유지와 왕복 제약 명시, 최소 버전 3.10 변경 중 선택을 요청했고 “최소 Python 버전을 3.10으로 변경” 승인을 받았다.
- [요구사항](../REQUIREMENTS.md)에 R6·A13을 추가하고 [계획](../PLAN.md)에 버전 선언 및 wheel 메타데이터·최소/최고 지원 버전 검증을 추가했다.
- Python 3.10의 공식 [What's New](https://docs.python.org/3.10/whatsnew/3.10.html)도 확인했다. 괄호로 묶는 컨텍스트 관리자·union 문법 등은 이번 문제 해결에 필요하지 않아 일괄 도입하지 않으며 `Optional[List[str]]` 관례를 유지한다. 제거할 버전 조건부 코드나 backport 의존성은 발견하지 못했다.
- 한국어·영어 신규 매뉴얼 예시는 내용이 동일하고 실제 실행·assert가 통과했다. 처음 시도한 한글 제목 기반 추출은 셸 인코딩 때문에 실패해 ASCII 코드 식별자로 추출하여 재실행했다.

Python 3.9의 실패를 테스트 생략이나 성공 처리로 숨기지 않았다. 이후 완료 판단은 승인된 지원 범위 3.10~3.14를 기준으로 한다.
