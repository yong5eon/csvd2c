# CSV iterator 프로토콜 지원

- 이제 열린 파일 컨텍스트에서 `next(csv)`와 `for record in csv`로 레코드를 순차적으로 읽을 수 있습니다. 기존 `row()`와 `rows()`를 계속 사용할 수 있으며 모두 같은 읽기 위치와 Validator 설정을 공유합니다.
- EOF와 limit 도달 시 반복이 정상적으로 끝나고, 검증 오류가 발생한 레코드는 소비된 뒤 다음 호출에서 다음 레코드를 읽습니다.
- iterator는 `CSV` 인스턴스이며 열린 파일에서 사용해야 합니다. 닫힌 파일에서는 기존 단일 행 읽기와 같이 `RuntimeError`가 발생합니다.
