# CSV iterator 프로토콜 구현

`src/CSV.py`에 `__iter__()`와 `__next__()`를 추가했다. `iter(csv)`는 같은 객체를 반환하고, `next(csv)`는 `rows()`의 다음 결과를 사용해 기존 reader 위치·offset·limit과 생성자 Validator 처리를 공유한다. `rows()` 경로를 재사용해 EOF는 `StopIteration`, Validator가 발생시킨 `StopIteration`은 `RuntimeError`로 처리한다.

`tests/test_csv.py`에 iterator와 `row()`·`rows()` 간 cursor 공유, 생성자 Validator, limit·EOF, 닫힌 상태와 재오픈, 검증 실패 뒤 재개를 확인하는 검증을 추가했다. `samples/reject_records.py`는 실패 레코드 처리 루프에서 `next(csv)`를 사용한다. 양언어 상세 매뉴얼 및 루트 빠른 시작 문서를 갱신했다.

실행 결과: `test_csv.py` 49개 통과, 거부 레코드 샘플 직접 실행 성공, `git diff --check` 통과. 전체 suite와 원격 CI는 실행하지 않았다.
