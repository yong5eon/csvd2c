# CSV 읽기 범위 구현과 테스트

[작업 계획](../PLAN.md)의 1~3단계를 수행했다.

## 변경 내용

`src/CSV.py`

- 생성자에 키워드 인자 `offset: int = 0`, `limit: Optional[int] = None`을 추가했다. 생성자 `offset=None`은 `TypeError`로 거부한다.
- `open(path, mode='rb', header=None, offset=None, limit=None)`로 확장했다. 인자별로 `None`이면 생성자 값을 쓰며, 적용 값은 `open()` 지역에서 정해 재오픈 시 남지 않는다.
- `check_range()`: `bool`이거나 `int`가 아니면 `TypeError`, 음수면 `ValueError`. `open()`에서는 파일을 열기 전에 검사한다.
- 열린 파일 단위 상태 `skip`(남은 offset), `remaining`(남은 limit, `None`은 제한 없음)을 추가했다. reader 생성 직후, 헤더 검증 전에 초기화하므로 헤더 레코드는 세지 않는다. `close()`에서 초기화한다.
- `read_record()`를 추가하고 `row()`와 `iterate()`의 `next(source)`를 교체했다.

```python
# src/CSV.py 발췌 (독립 실행 불가)
def read_record(self, source):
  if self.remaining == 0:
    raise StopIteration
  while self.skip > 0:
    next(source)
    self.skip -= 1
  record = next(source)
  if self.remaining is not None:
    self.remaining -= 1
  return record
```

- limit 검사를 건너뛰기 전에 하므로 `limit=0`은 offset 구간도 읽지 않는다. `remaining`은 레코드를 받은 뒤 검증 전에 줄이므로 검증 실패 레코드는 limit에 포함되고, 파싱 오류로 받지 못한 레코드는 포함되지 않는다.
- `iterate()`는 기존처럼 `StopIteration`을 잡아 순회를 종료한다. `row()`·`rows()`·`header()`의 시그니처는 바꾸지 않았다.
