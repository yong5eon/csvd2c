# 작업 계획 작성

[요구사항 명세](../REQUIREMENTS.md)와 현재 코드·테스트·문서를 대조하여 [작업 계획](../PLAN.md)을 작성했다.

- 변경 범위를 `src/CSV.py`로 한정하고, `row()`·`iterate()`가 공통으로 쓰는 레코드 읽기 메소드에서 offset·limit을 처리하기로 했다. 두 경로가 같은 상태를 쓰므로 혼용·재호출 결과가 같아진다.
- limit 검사를 offset 건너뛰기보다 먼저 하여 `limit=0`에서 offset 구간도 읽지 않게 했다.
- 기존 `samples/bounded_batches.py`는 배치 분할 예제이며 offset·limit 우회 코드가 아니어서 변경 대상에서 제외했다. 범위 예제는 `samples/read_range.py`로 추가한다.
- 검증 명령은 #10에서 사용한 설치·테스트·Pyright 절차를 따른다.
