# Python 3.9·3.10 테스트 입력 호환성 수정

GitHub Actions의 Python 3.9와 3.10 잡에서 `test_invalid_escapechar_propagates_reader_error`가 실패했습니다. 실패 조건은 `escapechar=''`였으며, 이 Python 버전에서는 빈 문자열을 허용해 테스트가 기대한 `TypeError`가 발생하지 않았습니다. Python 3.11 이상은 빈 `escapechar`를 거부하므로 기존 테스트는 지원 버전 간 동작 차이에 의존했습니다.

`tests/test_csv.py`의 잘못된 설정을 두 문자 `xx`로 변경했습니다. 표준 `csv.reader`가 모든 지원 버전에서 거부하는 입력으로 오류 전파 계약을 검사하도록 한정했으며, 제품 코드와 공개 동작은 변경하지 않았습니다.

최종 검증 결과는 최신 작업 기록을 참고하세요.
