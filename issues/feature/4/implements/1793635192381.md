# `escapechar` 사용 문서 반영

한국어 [사용 매뉴얼](../../../docs/README.md)과 영어 [사용 매뉴얼](../../../docs/README.en.md)에 `escapechar`의 기본값 `None`, Python 표준 `csv.reader`를 따르는 파싱·설정 오류 동작과 backslash 사용 예시를 추가했습니다. 두 문서의 설정과 기대 필드 값을 일치시켰습니다.

이슈 기록의 [변경 로그](../CHANGELOG.md)에 고객이 사용할 수 있는 옵션과 기본 동작을 안내했습니다. 전체 매뉴얼 테스트 및 링크 검증 결과는 작업 기록에 남겼습니다.
