# 사용자 요구 기반 요구사항 초안 작성

[이전 분석](./1793689049733.md)과 사용자 요구 6개를 바탕으로 [요구사항 명세](../REQUIREMENTS.md)를 작성했다.

- 사용자 요구: 별도 헤더 검증기, 생성자·`open()`의 `header` 인자, `cols` → `column`, 헤더 검증기가 있으면 `open()` 시점 검증, `header()`는 저장된 검증 헤더 반환, 검증이 없었으면 `None`.
- 이슈 원문과 충돌하는 검증 체계·인자 이름·검증 시점·미주입 시 동작은 사용자 요구를 우선하고 차이를 명세 첫 표에 남겼다.
- `cols` 사용처는 `src` 29곳, 테스트·샘플·매뉴얼·루트 README 14개 파일이다.
- 헤더 검증기 구성 범위, 출력 `header` 인자 처리, `column` 변경 범위, 빈 파일 동작, 헤더 Pattern 이름·중복 집합 처리, 병합 대상은 확인 필요로 남겼다.
- 제품 코드는 변경하지 않았다.
