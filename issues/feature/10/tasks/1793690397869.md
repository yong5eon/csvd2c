# 확정 요구사항 기반 작업 계획 작성

[요구사항 명세](../REQUIREMENTS.md)를 바탕으로 [작업 계획](../PLAN.md)을 작성했다.

- 패키지 구성: `src/row`와 같은 `Error`·`Pattern`·`Validator`·`patterns` 구조를 확인했다. `setup.py`는 `find_packages`로 `src` 하위 패키지를 포함하므로 새 `header` 패키지를 위한 설정 변경은 필요 없다.
- 영향 범위: `header()` 사용 샘플 11개·테스트 5개, 출력 `header` 사용 샘플 5개·테스트 5개, `cols` 사용 14개 파일을 확인했다.
- 헤더 Pattern 이름은 `RejectEmptyNames`, `RejectDuplicateNames`, `RequireNames`, `ExactNames`, `ExactOrder`로 제안했다. 이후 사용자 요청으로 `Names` 접미사를 빼고 `RequireNames`를 `Includes`로 바꿔 `RejectEmpty`, `RejectDuplicate`, `Includes`, `Exact`, `ExactOrder`로 확정했다. 이어서 사용자 요청으로 헤더 컬럼 수 검사 `Length(count)`를 추가했다. 빈 이름 거부는 각 이름만 검사하므로 빈 헤더 라인(`[]`)은 `Length` 등으로 거부한다.
- 이름 변경·공백 제거·BOM 제거·뒤쪽 빈 헤더 제거 Pattern은 이슈 요청이 없고 사용자 정의 Pattern으로 대신할 수 있어 추가하지 않기로 했다. 매뉴얼에 이름을 바꾸는 사용자 정의 Pattern 예시만 넣는다. 사용자 확인으로 계획을 확정했다.
- 제품 코드는 변경하지 않았다.
