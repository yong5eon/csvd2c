# 구현 검증

[구현](../implements/1793691383141.md) 후 작업 전용 격리 환경에서 저장소 루트를 기준으로 검증했다.

```shell
python -m pip install --force-reinstall .
python -m unittest discover -s tests
pyright --pythonpath <검증 환경의 Python> --pythonversion 3.9 src tests samples
```

- 일반 wheel 설치 후 전체 테스트 147개 통과. 샘플 23개 실행 테스트 포함. 변경 전 124개에서 출력 `header` 전용 테스트 6개를 지우고 헤더 테스트 29개 등을 추가했다.
- wheel 설치본에서 `csvd2c.header.patterns`의 6개 Pattern import를 확인했다.
- Pyright 1.1.414 진단은 `master` 추출본 기준선 23개, 현재 23개다. 파일명·규칙·메시지 비교에서 신규 진단은 0개다.
- 루트 README·상세 매뉴얼의 Python 코드 블록 33개를 Python 3.9 문법으로 분석하고, 파일 입력이 없는 assertion 예제 12개를 실행했다.
- 문서 상대 링크, 이슈 문서의 개인 절대 경로, `git diff --check` 검사를 통과했다.
- 매뉴얼 영향 검토: 공개 API가 바뀌므로 한국어·영어 매뉴얼과 루트 README를 갱신했다.
