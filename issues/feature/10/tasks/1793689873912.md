# 헤더 패키지·검증 호출·병합 대상 확정 반영

사용자 결정을 [요구사항 명세](../REQUIREMENTS.md)에 반영했다. [이전 초안 기록](./1793689391005.md)의 확인 항목 중 다음을 확정했다.

- `csvd2c.header` 패키지에 `Validator`, `Pattern`, `Error`를 둔다.
- 헤더 검증 호출은 `List[str] -> List[str]`이며 라인 번호·열 식별자를 받지 않는다. 헤더 `Error`도 라인·열 정보를 갖지 않는다.
- `cols` → `column` 변경은 생성자와 `row()`·`rows()`에 모두 적용한다.
- 헤더 검증기가 있는데 빈 파일이면 헤더 `Error`를 발생시킨다.
- 헤더 이름 중복은 별개 헤더로 보며, 정확한 구성 검사는 정렬한 이름 목록을 비교한다.
- 병합 대상은 `master`다.

사용자는 `row()`·`rows()`에 출력 `header` 인자가 없다고 보았으나, 현재 `src/CSV.py`의 `row()`·`rows()`에 출력용 `header` 인자가 있고 상세 매뉴얼과 샘플 5개가 사용한다. 이 인자 처리와 헤더 `Error`의 `value` 포함 여부는 확인 필요로 남겼다.

후속 사용자 결정으로 헤더 `Error`는 `__init__(message, value: Optional[List[str]])`로 확정했다. 검증 실패 시 실패한 Pattern의 입력 헤더, 빈 파일이면 `None`이다.

이어서 `row()`·`rows()`의 출력용 `header` 인자를 제거하기로 확정했다. CSV는 읽기·검증 역할이고 헤더 이름 변경은 헤더 검증기가 담당하기 때문이다. 헤더 검증기 없이 헤더가 있는 파일을 읽으면 첫 결과가 헤더 레코드인 것은 호출자 의도로 본다. 이로써 확인 필요 사항이 모두 확정되었다.
