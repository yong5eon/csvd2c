# 헤더 검증기와 CSV API 변경 구현

[작업 계획](../PLAN.md)의 1~5단계를 구현했다.

## csvd2c.header 패키지

- `src/header/Error.py`: `Error(BaseError)`, `__init__(message, value: Optional[List[str]])`, 속성 `value`.
- `src/header/Pattern.py`: 추상 `__call__(self, value: List[str]) -> List[str]`.
- `src/header/Validator.py`: Pattern을 순서대로 적용하고 최종 반환값을 돌려준다. Pattern이 아닌 인자는 `row.Validator`와 같이 `RuntimeError`.
- `src/header/patterns/`: `RejectEmpty`, `RejectDuplicate`, `Length`, `Includes`, `Exact`, `ExactOrder`. 실패 시 입력 헤더를 담아 `Error`를 발생시키고, 성공하면 입력을 그대로 반환한다. `Exact`는 `sorted(value) != sorted(names)`로 비교해 중복 이름을 각각 센다.
- `setup.py`의 `find_packages`가 새 패키지를 자동 포함한다. wheel 설치본에서 import를 확인했다.

## src/CSV.py

- 생성자에 `header`를 추가하고 `cols`를 `column`으로 바꿨다. `check_header()`가 헤더 Validator 타입을 검사한다.
- `open(path, mode, header=None)`: `header`가 `None`이면 생성자 값을 쓰는 지역 변수 `validator`를 정한다. reader 생성 뒤 기존 `try`/`finally` 안에서 `read_header()`를 호출하므로, 실패하면 `close()`가 파일과 상태를 정리하고 예외가 `open()` 호출자에게 전파된다.
- `read_header()`: 레코드가 없으면 `HeaderError(..., None)`, 있으면 Validator 반환값의 복사본을 헤더로 저장한다.
- `header()`: 레코드를 읽지 않고 저장된 헤더의 복사본 또는 `None`을 반환한다.
- `row()`·`rows()`의 출력 `header` 인자, `@overload` 6개, `prepare_header()`, `format_record()`를 제거했다. `row()`는 `List[str]`, `rows()`는 `Generator[List[str], None, None]`을 반환한다.
- 헤더가 열린 동안 바뀌지 않으므로 `iterate()`는 reader 교체만 확인한다.
- 이름 기반 열 검증기를 헤더 없이 쓰면 `RuntimeError('Inject a header Validator before using named column validators')`. 매핑 조건 `ValueError`는 유지했다.

```python
# 변경 전 (발췌)
def header(self) -> List[str]:
	self.header_data = next(source)
	return self.header_data.copy()

# 변경 후 (발췌)
def header(self) -> Optional[List[str]]:
	if self.header_data is None:
		return None
	return self.header_data.copy()
```
