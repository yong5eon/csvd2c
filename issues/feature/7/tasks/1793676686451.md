# 호출자 오류 처리 정책의 자율성 반영

- 사용자 확인에 따라 예외 발생 여부·예외 타입·입력 유지·기록·복구 동작은 사용하는 쪽에서 결정하도록 [요구사항 명세](../REQUIREMENTS.md)를 정정했다.
- 기본 Error 제공과 Error 지정 필수 사이의 선택을 요구사항이나 차단 사항으로 두지 않는다. 모든 Pattern에 예외 발생을 강제하지 않는다.
- 이전 기록의 Pattern 직접 예외 금지 표현은 라이브러리 검증 실패의 Error 활용 방향으로 한정하며, 사용자 정의 Pattern·Error의 처리 자율성을 제한하지 않도록 명세·인수 기준·README·종합 기록을 갱신했다.
- 맥락 보존, 반환값의 후속 Pattern 전달, 실제 발생한 예외의 전파 요구는 유지했다. 제품 코드는 변경하지 않았다.
