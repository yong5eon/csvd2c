# 열 식별자 타입 명세 보완

- 사용자 요청의 `Union[int, str]`를 열 식별자 계약에 반영했다. 숫자 인덱스와 문자열 컬럼명을 하나의 식별자로 전달한다.
- 기존 CSV 지정 방식에 맞춰 튜플 지정은 0부터 시작하는 인덱스, 이름 지정은 지정한 컬럼명을 전달하도록 명세했다.
- 식별할 수 없는 경우는 `None`으로 표현하며, 컬럼 값과 복구 반환값의 `str` 계약은 유지했다.
- [요구사항 명세](../REQUIREMENTS.md)의 전달 정보와 인수 기준을 갱신했다. 제품 코드는 변경하지 않았으며 행 구조 변경 후 원본 컬럼 대응은 여전히 미확정이다.
