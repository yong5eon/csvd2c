# 격리 환경 구성과 초기 회귀 검증

- 시스템 Python의 패키지 조회는 `csvd2c` 누락으로 실패했고 외부 패키지의 site 초기화 오류도 출력되었다. 외부 환경은 수정하지 않고 작업 전용 격리 가상환경에 csvd2c를 편집 설치했다.
- 테스트·샘플 Python 파일 32개의 Python 3.9 문법을 확인했다.
- `python -m unittest discover -s tests -p "test_error_context.py" -v`: 새 회귀 테스트 9개 통과.
- 전체 기존·신규 Python 테스트 122개를 실행했다. 첫 실행은 `IfLength` 외부 `error=` 호출 한 곳에서 실패했고, 내부 Pattern에 지정하도록 수정했다.
- 두 번째 전체 실행은 Error 구현의 리스트 변경이 호출자 행에 영향을 주는 회귀를 확인했다. 파일 최초 원본 추적이 아닌 기존의 Pattern 입력 복사 보호를 유지하도록 소스 보완을 진행한다.
- Pyright 명령 누락을 확인해 격리 검증 환경에 도구를 설치했다. 초기 타입 검증은 편집 설치의 import 해석 문제와 기존 타입 진단을 출력했으며, 설치된 wheel 기준과 변경 전 진단을 구분하여 최종 확인할 예정이다.

최종 통과 결과는 후속 기록에 남긴다. 검증 환경과 보조 변환 스크립트는 저장소 밖 임시 도구이며 제품 파일에 포함하지 않는다.
