# 예외 설계 정정 후 최종 검증

[예외 설계 정정](../implements/1793679516850.md) 후 작업 전용 격리 환경에서 저장소 루트를 기준으로 검증했다. [이전 중간 검증](./1793678360053.md)의 행 입력 복사 회귀는 처리기 설계 자체를 제거하면서 대상이 사라졌다.

```shell
python -m pip install --force-reinstall .
python -m unittest discover -s tests
pyright --pythonpath <검증 환경의 Python> --pythonversion 3.9 src tests samples
```

- 일반 wheel 빌드·설치 후 전체 테스트 124개 통과. 샘플 22개 실행 테스트 포함.
- Pyright 1.1.414 진단은 변경 전 HEAD 기준선 28개, 현재 23개였다. 파일명·규칙·메시지 비교에서 신규 진단은 0개다. 감소분은 잘못된 `error=` 인자를 넘기던 테스트를 제거한 결과다. 남은 진단은 기존 문제이며 수정하지 않았다.
- 루트 README·상세 매뉴얼의 Python 코드 블록 29개를 Python 3.9 문법으로 분석하고, 파일 입력이 없는 assertion 예제 10개를 실행했다.
- `src`·`tests`·`samples`·문서에서 `error=` 사용과 처리기 호출이 남지 않았음을 검색했다. 문서에 남은 `error=`는 제거 안내 문구다.
