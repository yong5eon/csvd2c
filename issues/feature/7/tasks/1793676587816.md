# 행 변환 이후 열 검증 기준 확정

- 사용자 확인에 따라 열 검증은 행 Pattern 적용과 행 Error 복구 완료 후 변경된 행을 기준으로 수행하도록 [요구사항 명세](../REQUIREMENTS.md)를 갱신했다.
- 클린징 전 컬럼 값은 해당 열 검증 체인의 시작 값으로 보존한다. 행 변환 전 원본 배열은 별도로 유지하며 필드 역추적은 하지 않는다.
- 기존 헤더 기반 이름 지정 Validator의 인덱스 선택은 유지하고 변경된 행의 선택 위치에 적용하도록 정리했다.
- 이전 기록의 컬럼 원본 대응 미확정 상태를 이번 결정으로 해소했다. README·종합 기록·인수 기준을 갱신했으며 제품 코드는 변경하지 않았다.
