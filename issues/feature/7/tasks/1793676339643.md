# Pattern 검증 실패의 Error 경유 처리 명세

- 후속 요청에 따라 Pattern의 데이터 검증 실패는 직접 `ValueError` 발생·재발생 대신 해당 행·열 Error의 `__call__`로 처리하도록 [요구사항 명세](../REQUIREMENTS.md)를 수정했다.
- 내부 검증 예외는 실패 원인으로 전달하되 Error 구현에서 발생한 예외는 재처리하지 않는다. 생성자 설정 오류와 명시된 후보 복구 실패 동작은 구분하여 유지한다.
- 기존 Error가 호출 가능한 처리 클래스라는 계약을 유지했다. 예외 클래스로의 전환은 확정하지 않았다.
- 원본 이슈의 Error 미지정 실패 동작 유지와 후속 요구 사이의 변경을 명시했다. 기본 Error 제공 또는 Error 지정 필수 여부는 확인이 필요하며 구현하지 않았다.
