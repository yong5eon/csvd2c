# 원본값을 Pattern 입력값으로 정정

- 사용자 확인에 따라 원본값을 파일 최초 값이나 체인 시작 값이 아닌 해당 Pattern의 입력값으로 [요구사항 명세](../REQUIREMENTS.md)에 정정했다.
- `Strip`이 공백을 빈 문자열로 바꾼 뒤 `Required`가 실패하면 Error에 전달되는 값도 빈 문자열이다. 최초 원본 배열·열 체인 시작 값의 별도 보존 요구와 관련 인수 기준을 제거했다.
- 앞선 사용자 확인의 행 `(List[str], int) -> List[str]`, 열 `(str, int, Union[int, str]) -> str` 계약을 Pattern·Validator·Error 모두에 반영했다. 열 식별자에 `Optional`을 사용하지 않으며, 실패 원인이나 전체 최초 원본 행을 별도 인자로 강제하지 않는다.
- 원본 이슈 본문은 그대로 보존하고 후속 확인이 최초 원본 보존 요구를 대체함을 명시했다. 이전 단계별 기록은 당시 결정을 보존하며 이번 기록으로 정정한다.
- README·종합 기록을 동기화했다. 제품 코드는 변경하지 않았다.
