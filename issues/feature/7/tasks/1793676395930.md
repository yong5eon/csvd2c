# 식별 불가능한 실패의 공통 Error 명세

- 후속 요청에 따라 최상위 `csvd2c.Error` 추가와 기존 행·열 Error의 상속 관계를 [요구사항 명세](../REQUIREMENTS.md)에 반영했다.
- 식별 불가능한 검증 실패는 공통 Error로 처리하고 확보하지 못한 정보는 만들어내지 않는다. 행 단위 실패와 헤더 없이 숫자 인덱스로 식별 가능한 열 실패는 기존 행·열 Error의 대상으로 구분했다.
- 기존 `__call__` 기반 처리 방향을 유지했다. 공통 Error의 주입 위치·구체적인 호출·반환 계약은 미확정으로 표시했다.
- Error 미지정 정책과 파싱·디코딩 실패 처리 범위는 이 요청만으로 변경하지 않았다. 제품 코드는 변경하지 않았다.
