# PR #8 리뷰 반영

[PR #8](https://github.com/yong5eon/csvd2c/pull/8)의 Copilot 리뷰 지적 4건을 사용자 지시에 따라 반영했다.

| 지적 | 반영 |
| --- | --- |
| [행 검증 후 지정 열 누락이 `ValueError`](https://github.com/yong5eon/csvd2c/pull/8#discussion_r4451025463) | `src/CSV.py`의 `validate()`가 `row.Error(message, row, record)`를 발생시킨다. 레코드는 이미 읽은 상태이고 레코드마다 달라지는 데이터 실패이므로 행 Error로 분류했다. 헤더 이름 중복·누락은 설정 오류라 `ValueError`로 유지했다. |
| [사용자 정의 행 Pattern의 오류 예시 없음](https://github.com/yong5eon/csvd2c/pull/8#discussion_r4451025513) | `samples/custom_patterns.py`에 `RowError`를 발생시키는 `RejectComment`를 추가하고, 4번 라인의 주석 레코드에서 `row`·`value`를 확인한다. |
| 거부 기록 값을 "원본"으로 설명 | 상세 매뉴얼과 샘플 안내(한국어·영어)를 "검증에 실패한 값"으로 정정했다. |
| Pattern 독스트링 예시에 `Error` import 없음 | 행·열 `Pattern` 독스트링 예시에 import를 추가했다. |

- `tests/test_csv.py`의 `test_missing_column_after_row_validation`이 `RowError`의 `row`·`value`를 확인하고, 다음 `row()`로 다음 레코드를 읽는지 검증하도록 바꿨다.
- [PLAN](../PLAN.md)의 제외 범위 문구, 매뉴얼, [CHANGELOG](../CHANGELOG.md)에 이 동작을 반영했다.

검증은 [작업 기록](../tasks/1793685462491.md)을 따른다.
