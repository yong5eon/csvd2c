# 테스트·샘플 호출과 사용자 안내 갱신

- 행·열 사용자 정의 Error·Pattern과 직접 호출을 확정된 라인·열 식별자 인자에 맞춰 갱신했다.
- `tests/test_error_context.py`에 Pattern 입력값, 마지막 물리 라인, 숫자·이름 열 식별자, 행 변환 후 열 검증, 중첩 예외 전파와 다음 레코드 읽기 검증을 추가했다.
- `samples/custom_errors.py`에 위치 정보 기록, 입력 유지와 공통 Error 사용자 구현을 추가하고 `samples/custom_patterns.py`가 입력값·위치를 열 Error로 전달하도록 변경했다.
- `samples/reject_records.py`는 별도 원본 읽기·검증 루프 대신 CSV에 Validator를 직접 주입하며, 사용자 정의 Error가 JSONL에 입력값·라인·이유를 기록한 뒤 사용자 정의 예외를 발생시킨다. 호출자는 이 예외만 처리하고 다음 `row()`를 읽는다.
- 한국어·영어 README·상세 매뉴얼·샘플 안내에 새 호출 계약과 마이그레이션, Pattern 입력값 기준과 처리 정책의 자율성을 반영했다.
- `IfLength` 외부 `error=` 제거에 맞춰 내부 검증 Pattern으로 Error를 지정하는 마이그레이션을 테스트·매뉴얼에 반영했다. Error가 발생시킨 예외를 외부 조건 Pattern이 복구 값으로 바꾸지 않도록 하기 위한 변경이다.

검증은 진행 중이며 제품 소스 구현·최종 회귀 확인 후 종합한다.
