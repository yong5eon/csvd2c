# 호출 인자 이름을 value·row로 변경

사용자 요청에 따라 행·열 `__call__`과 Error의 라인 번호 이름을 `row`로, 처리 대상 값을 `value`로 바꿨다. 적용 범위는 사용자 확인에 따라 행·열 `__call__`과 Error 속성 전체다.

| 대상 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 행 Pattern·Validator | `__call__(row, line)` | `__call__(value, row)` |
| 열 Pattern·Validator | `__call__(col, line, column)` | `__call__(value, row, column)` |
| 행 Error | `Error(message, line, value)`, 속성 `line` | `Error(message, row, value)`, 속성 `row` |
| 열 Error | `Error(message, line, column, value)`, 속성 `line` | `Error(message, row, column, value)`, 속성 `row` |

- `src`·`tests`·`samples`의 `__call__`은 AST로 대상 함수를 찾아 함수 안의 이름만 바꿨다. 속성 접근(`self.value` 등)은 바꾸지 않았다.
- 기존 지역 변수 `value`와 충돌하는 3곳은 먼저 이름을 바꿨다. `Date`는 `parsed`, `Range`는 `number`, `RejectEmpty`는 `field`를 쓴다.
- 일괄 변경 도구가 일부 들여쓰기의 탭을 공백으로 바꾼 것을 확인했다. 문자열 밖의 줄만 같은 개수의 탭으로 복원했고 `git diff --check`로 확인했다.
- `reject_records.py` 샘플의 JSONL 키도 `line`에서 `row`로 바꿨다.
- 매뉴얼·루트 README·샘플 안내·이슈 문서의 시그니처와 속성 이름을 함께 바꿨다.
- `CSV.py` 내부 지역 변수 이름은 공개 계약이 아니므로 바꾸지 않았다.
