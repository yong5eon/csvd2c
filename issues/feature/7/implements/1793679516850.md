# Error를 예외 클래스로 정정하고 Pattern의 error= 제거

[이전 구현 기록](./1793677881530.md)과 이전 소스 작업은 Error를 `__call__`로 호출하는 처리기로 유지했다. 사용자는 Error를 예외 클래스로 사용하라고 지시했고, 이전 설계는 요구사항 근거 없이 기존 구조를 유지한 판단 오류였다. 사용자 확인에 따라 상속 대상은 `Exception`, Pattern의 `error=`는 제거로 확정했다.

## 변경 내용

- `src/Error.py`: 공통 `Error(Exception)`, `__init__(message)`, 속성 `message`.
- `src/row/Error.py`: `Error(BaseError)`, `__init__(message, line, value: List[str])`, 속성 `line`, `value`.
- `src/column/Error.py`: `Error(BaseError)`, `__init__(message, line, column: Union[int, str], value: str)`, 속성 `line`, `column`, `value`.
- 행 Pattern 8개(`Length`, `RejectEmpty`, `RejectHeader`, `Merge`, `Reorder`, `Remove`, `Split`, `Replace`)와 열 Pattern 14개(`Required`, `Length`, `Regex`, `Choices`, 손상 문자 검사 3개, `Map`, `Date`, `Number`, `Range`, `Currency`, `Recode`, `RecoverEncoding`)의 `error=` 매개변수, 타입 검사와 처리기 호출을 제거했다. 데이터 실패 시 해당 Pattern의 입력값을 담아 Error를 직접 발생시킨다.
- 행·열 `Pattern` 독스트링 예시도 Error 발생으로 바꿨다. Pattern·Validator의 위치 인자 호출 계약은 그대로 유지했다.

```python
# 변경 전 (발췌)
if self.error is not None:
	return self.error(col, line, column)
return Error('A nonempty value is required')(col, line, column)

# 변경 후 (발췌)
raise Error('A nonempty value is required', line, column, col)
```

## 함께 수정한 범위

- 테스트·샘플은 처리기와 `error=`를 제거하고, 데이터 실패의 `ValueError` 기대를 행·열 Error와 속성 검증으로 바꿨다. 처리기 복구·파일 기록 핸들러 전용 테스트는 제거했고, Error가 호출 가능하지 않다는 테스트를 추가했다.
- 한국어·영어 매뉴얼, 루트 README, 샘플 안내의 계약 설명과 예시를 예외 방식으로 바꿨다.
- 생성자 설정 오류는 기존처럼 `TypeError`·`ValueError`를 즉시 발생시킨다.
