# csvd2c

csvd2c는 **CSV Dirty to Clean**의 약자로, 불규칙한 대용량 CSV 데이터를 스트리밍 방식으로 검증하고 정제하기 위한 Python 라이브러리입니다.

## 개발 상태

현재 저장소 초기화 단계이며, 라이브러리 코드와 설치 가능한 패키지는 아직 제공하지 않습니다. 아래 기능과 처리 원칙은 구현 목표입니다.

## 제공 예정 기능

- **파일 인코딩 감지**: 제한된 샘플을 검사하여 인코딩 후보를 제시하고, 인코딩을 직접 지정할 수 있도록 지원합니다. 감지 결과는 전체 파일의 인코딩을 보장하지 않습니다.
- **헤더와 데이터 분리 읽기**: 헤더를 별도로 제공하고 데이터 레코드를 순차적으로 읽습니다. 따옴표 안의 개행을 고려하여 물리적인 줄과 CSV 레코드를 구분합니다.
- **레코드 구조 검사 및 치환**: 헤더와 컬럼 수의 일치 여부 등 구조를 검사하고, 사용자가 지정한 규칙에 따라 구조를 보정하고 다시 검사할 수 있도록 지원합니다.
- **컬럼 검사 및 치환**: 컬럼별 값의 유효성을 검사하고, 사용자가 지정한 규칙에 따라 값을 정규화하고 다시 검사할 수 있도록 지원합니다.

## 처리 원칙

- 200GB를 넘는 입력도 파일 전체나 처리 결과 전체를 메모리에 적재하지 않고 순차적으로 처리하는 것을 목표로 합니다. 개별 레코드의 크기와 처리 배치 크기는 메모리 사용량에 영향을 줍니다.
- 원본을 보존하고, 보정한 값과 처리 사유를 구분할 수 있도록 합니다.
- 모호한 날짜나 손상된 문자열을 임의로 추측하여 복구하지 않습니다.
- 디코딩 오류, CSV 파싱 오류, 구조 오류와 컬럼 검증 실패를 구분하여 보고합니다.
- 정상 결과, 보정 결과와 확인이 필요한 데이터를 구분하여 전달합니다.
